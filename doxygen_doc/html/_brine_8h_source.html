148 @section motivation Motivation
149 Brine is legacy code from Thomas Driesner's developments for the H2O-NaCl system, but it is REQUIRED in the CSMP context. There, it is essential to build accurate lookup tables for the H2O-NaCl system, which are then actually used by CSMP. As long as we don't distribute the lookup tables per se for the various platforms, the Brine legacy will remain in CSMP.
150
151 Brine computes the properties of H<sub>2</sub>O-NaCl fluids as a function of temperature-pressure-composition [Celsius, bar, mole fraction NaCl] , according to the paper
152
153 Driesner T. (2007): The system H2O-NaCl. Part II: Correlations for molar volume, enthalpy, and isobaric heat capacity from 0 to 1000oC, 1 to 5000 bar, and 0 to 1 XNaCl. Geochimica et Cosmochimica Acta 71, 4902-4919.
154
155 @section usage Usage
156 Construct an instance of "Brine" with the temperature (in C), Pressure (Pa) and NaCl Concentration (mass fraction) that live in your code part as constructor arguments. "Brine" has an internal mechanism (via const&) to make sure that it always uses the current values of temperature, pressure, and composition that you have calculated externally. Public member names should be self-explanatory. Don't experiment with making private memebrs public as that will almost inevitably lead to wrong results!
157
158 @code
159 double temperature(100.0); // temperature in your code
160 double fluid_pressure(10.0e6); // fluid pressure in your code
161 double massfraction_nacl(0.1); // mass fraction NaCl in fluid, in your code
162
163 Brine brine(temperature, fluid_pressure, massfraction_nacl); // instantiate a Brine object
164
165 ... // simulation goes on
166
167 // new values for temperature, fluid pressure, and composition have been computed:
168 temperature = newtemperature;
169 fluid_pressure = new_fluid_pressure;
170 massfractionnacl = new_massfraction_nacl;
171
172 // retrieve and assign new fluid properties, no need to new communicate he new temperature, fluid pressure, and composition, they are "known" automatically by Brine
173 rho = brine.Density();
174 mu = brine.Viscosity();
175 cp = brine.HeatCapacity();
176
177 ... // move on
178 @endcode
179
180 @section dependencies Dependencies
181
182 @section issues Known issues
183 Performance is not optimized. Whenever one of the public members is invoked ALL properties are being computed. There is currently no intention to improve this as Brine should only be used to compute the lookup tables.
184 Pressure() still returns values in bars, a legacy from the SoWat development.
185 Composition() is in mole fraction NaCl, to convert to other units, the functions in "ConvertConcentrationUnitsNaCl.h" may be useful
186
187 @section testing Testing
188 testing was done in the period before publication in 2007, prior to writing this documentation, no details are available anymore
189 */
