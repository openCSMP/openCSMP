94/**
95@mainpage About
96
97The Complex Systems Modeling Platform (Open CSMP++) is an application programmer interface (API)
98for the simulation of THMC processes and their interactions in complex space and time domains.
99It primarily relies on combinations of finite element (FEM) and finite volue (FVM) methods for this purpose.
100Open CSMP++ was created as CSP in 1995 by Stephan K. Matthai and Stephen G. Roberts at Stanford University.
101
102Open CSMP++ has been designed for the simulation of complex physics in geometrically complex and scale-variant domains.
103Its modular structure aims to support analysis of the emergent properties of the studied system via mathematical simulations.
104Governing PDEs are integrated using FEM and FVM methods and combinations thereof.
105
106This core library of Open CSMP++ is distributed under the L-GPL license for general and including commercial use.

113 /**
114 Tests wheter a size_t or any other unsigned integer has been assigned a maximum value to signify that it has not been initialised.
115 (example: raw size_t's in CSMP are initialised to UINT_MAX, just as floating point values are initialised to a quiet NaN).
116 */
117 template<typename T>
118 bool constexpr isUninitialisedInteger( T i ) {
119 static_assert( std::is_integral<T>::value, "hasIntegerUnitialisedDefaultValue: inappropriate argument type for this function." );
120 static_assert( std::is_arithmetic<T>::value, "hasIntegerUnitialisedDefaultValue: inappropriate argument type for this function." );
121 static_assert( std::is_unsigned<T>::value, "hasIntegerUnitialisedDefaultValue: inappropriate argument type for this function." );
122 return ( i == std::numeric_limits<T>::max() );
123 }
