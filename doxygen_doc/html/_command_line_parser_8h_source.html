69@class CommandLineParser CommandLineParser "utilities/CommandLineParser.h"
70@author A. Burri
71@date 2003
72
73@section motivation Motivation
74
75Command line parser which allows for type-safe Unix-like command line
76parsing.
77
78
79@section design Design Intent
80
81The command line parser makes command line parsing safer and easier.
82Beside alleviating the need to do error-prone string parsing it offers
83sophisticated error handling capabilities through exception handling.
84
85Most Unix-like command line parsing feature are supported, like:
86- long and/or short options (like "-d" and "--double")
87- type-safe retrieval
88- optional arguments
89- listing of unused options
90- listing of non-arguments
91
92For a more complete overview of the functionality see the unit-test
93class of the CommandLineParser class.
94
95One specialty is that boolean options (i.e. command line flags) aren't
96allowed to take arguments, since they wouldn't be used anyway. So you
97are forced to use the end of options marker if you want to pass non-
98option arguments after a flag.
99
100
101@section applicability Applicability
102
103Parsing of command lines in the main function of a program.
104
105@section implementation Implementation
106
107Stand-alone class. Member template methods used. The command line is
108parsed in the constructor and the items can be retrieved using get
109functions.
110
111
112@section examples Application Examples
113
114@code
115int main(int argc, char** argv) {
116 CommandLineParser parser(argc, argv);
117
118 // Retrieving arguments
119 // ! Note that you have to specify the template parameter (return
120 // value parametrization) !
121 try {
122 double d = parser.get<double>("-d"); // mandatory argument
123 string s = parser.get<const char*>("-s", "Default");
124 // optional argument
125 int i = parser.get<int>("-i", "--int");
126 // choice between long and
127 // short option
128 bool b = parser.get<bool>("-b");
129 } catch (std::runtime_error& e) {
130 cout << e.what() << endl;
131 exit(1);
132 }
133
134 // Display if there are arguments which don't belong to an option
135 if (parser.operands()) {
136 cout << "Non-arguments: " << parser.getOperands() << endl;
137 }
138
139 // Display if there are unused arguments
140 if (parser.unused()) {
141 cout << "Unused: " << parser.getUnused() << endl;
142 }
143
144 // Output command line to screen
145 // (could be redirected to a file stream as well, as long as the file
146 // stream is opened before)
147 cout << parser;
148
149}
150@endcode
