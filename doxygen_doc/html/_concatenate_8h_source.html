31@class Concatenate Concatenate "interrelations/Concatenate.h"
32@author Adrian Burri
33@date 2002
34
35Concatenate is an interrelation which allows users to combine an
36arbitrary number of variables. An STL binary function object is used to
37define the operation used to combine the variables. For most
38applications, std::multiplies (for multiplication) and std::plus (for
39summation) of the STL base library will be used, but in principle one
40is free to define an arbitrary binary function.
41
42@attention for this interrelation to work all variables must have the
43same placement.
44
45
46@section applicability Applicability
47
48Use this interrelation when you need to combine different variables.
49
50
51@section implementation Implementation
52
53The implementation makes use of the STL binary function classes
54and the Operand class. Therefore, combining element and nodal variables
55should be possible (not tested). The first operand is used to
56initialize the result operand, which results in the following behaviour
57when using non-commutative operands (here shown for std::minus):
58
59@code
60 result_property = first_property - (\sum other_properties)
61@endcode
62
63If the result property is used as argument as well, first_property
64will be result_property, no matter at which position it was named in the
65list.
