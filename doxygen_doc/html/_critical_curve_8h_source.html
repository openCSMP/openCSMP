98 @section motivation Motivation
99 Although "CriticalCurve" is legacy code from Thomas Driesner's developments for the H2O-NaCl system, it is REQUIRED in the CSMP++ context. There, it is essential to build accurate lookup tables for the H2O-NaCl system, which are then actually used by CSMP++. As long as we don't distribute the lookup tables per se for the various platforms, the "CriticalCurve" legacy will remain in CSMP++.
100
101 "CriticalCurve" computes the temperature-pressure-molefraction [Celsius, Pa, mole fraction NaCl] coordinates of the critical curve of the system H2O-NaCl, according to the paper
102
103 Driesner T. and Heinrich C.A. (2007): The system H2O-NaCl. Part I: Correlation formulae for phase relations in temperature-pressure-molefraction space from 0 to 1000oC, 0 to 5000 bar, and 0 to 1 XNaCl. Geochimica et Cosmochimica Acta 71, 4880-4901.
104
105 @section usage Usage
106 Construct an instance of "CriticalCurve" with the temperature (in C) as constructor variable. "CriticalCurve" has an internal mechanism to make sure that it always uses the current value of that temperature. Public member names should be self-explanatory, I hope.
107
108 @code
109 double t; // temperature [C] in user's application
110 CriticalCurve critcurve(t);
111 @endcode
112
113 @section dependencies Dependencies
114 requires "CriticalPointH2O.h"
115
116 @section issues Known issues
117 Molefraction() is in mole fraction NaCl, to convert to other units, the functions in "ConvertConcentrationUnitsNaCl.h" may be useful
118
119 @section testing Testing
120 testing was done in the period before publication in 2007, prior to writing this documentation, no details are available anymore
121 */
