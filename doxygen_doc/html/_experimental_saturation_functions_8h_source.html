10/**
11 Saturation functions parameterised with experimental data, including
12 relperm- and pc-s relations read from user-specified data (ASCII-text)
13 files are interpolated with cubic splines.
14
15 Each curve is indentified by a unique integer code that represents the rocktype
16 of interest.
17
18 Input file format:
19
20 @code
21 To use experimental data for rock types you need to define
22 RELPERM_MODEL in Numerical.txt file as EXPERIMENTAL
23 Input file for rock types should be put in the execution folder
24 and the file name that contains relative permeability data and
25 capillary values should be 'rock type.txt'
26 File structure is as follow:
27 2 ->number of tables
28 1 ->rocktype
29 21 ->number of entries for table 0 (first table) excluding the first row
30 -1.99513 -0.00488 0.000125 3.709875 -10557.3 -519.567 ->derivatives at start and end for kro, krw and pc
31 0 1 0 5000 -> data (sw kro krw pc)
32 0.05 0.90024375 0.00000625 4472.135955
33 0.1 0.8019 0.0001 3162.27766
34 0.15 0.70624375 0.00050625 2581.988897
35 0.2 0.6144 0.0016 2236.067977
36 0.25 0.52734375 0.00390625 2000
37 0.3 0.4459 0.0081 1825.741858
38 0.35 0.37074375 0.01500625 1690.308509
39 0.4 0.3024 0.0256 1581.13883
40 0.45 0.24124375 0.04100625 1490.711985
41 0.5 0.1875 0.0625 1414.213562
42 0.55 0.14124375 0.09150625 1348.399725
43 0.6 0.1024 0.1296 1290.994449
44 0.65 0.07074375 0.17850625 1240.347346
45 0.7 0.0459 0.2401 1195.228609
46 0.75 0.02734375 0.31640625 1154.700538
47 0.8 0.0144 0.4096 1118.033989
48 0.85 0.00624375 0.52200625 1084.652289
49 0.9 0.0019 0.6561 1054.092553
50 0.95 0.00024375 0.81450625 1025.978352
51 1 0 1 1000
52 2 ->rocktype
53 6 ->number of entries for table 1 (second table) excluding the first row
54 -1 -1 1 1 0 0 ->derivatives
55 0 1 0 0 ->data
56 0.2 0.8 0.2 0
57 0.4 0.6 0.4 0
58 0.6 0.4 0.6 0
59 0.8 0.2 0.8 0
60 1 0 1 0
61 @endcode
62
63 @attention DO NOT SET ANY SATURATION ENDPOINTS (swr or snr) when using experimentally determined saturation functions
64 as these will naturally emerge from the curves.
65
66 @attention consequently, effective saturation also is already accounted for in terms of the spline values
67 negative values are avoided by returning 0 or 1 at saturations below and above the end-point saturations.
68
69 @author SKM
70 @date 14/1/2007
71 @update 9/2/2019
72
73*/
