11@brief Two-dimensional regular grid with interpolation operations and an optional halo
12across which interpolation still works; can be used for grid-point in finite-element cell transport computations.
13
14@author S.K. Matthai
15@date 28/7/97
16
17FiniteDifferenceGrid class implements a regular grid i {0,i_max-1}
18corresponding to the horizontal coordinate direction
19and j {0,j_max-1} corresponding to the vertical coordinate direction.
20Thus i=columns, j=rows.
21an operator(x,y) is provided to interpolate values within the
22grid domain.
23X(), Y() give x and y values corresponding to column and row indices
24of the regular grid, respectively.
25Val(i,j) is used to input and output values at the exact grid locations
26indicated by i(column=x) and j(row=y).
27
28*/
