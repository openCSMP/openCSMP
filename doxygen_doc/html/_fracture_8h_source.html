41/**
42
43This class provides a tool to model fractures and accurately handle fracture mechanics.
44
45@author M. Nejati
46@date 2016
47
48Extended by
49@author E. Pezzulli
50@date 2019
51
52@brief The Fracture class is a FractureTip Manager. It is responsible for the creation of fracture tips relevant to a split boundary, and their updating when a FractureTip propagates.
53 The Fracture class has 1 Fundamental requirement for creation
54 1) A split boundary
55
56 The Fracture class manages two fundamental data types
57 1) A collection of TipNodes.
58 2) A collection of FractureTips.
59
60 Construction involves: Identifying Tip Nodes of the splitboundary & constructing an associated FractureTip.
61
62 Propagation involves: A modification (without deletion/reconstruction) of the fracture tips and their associated tip nodes.
63
64 @attention From a User Perspective! When advancing to a new time step, the user must set run SetOldCoordinatesToCurrentTip()
65 in order to calibrate the old tip coordinate of all FractureTip objects (this ensures propagation velocity is calculated correctly every time step)
66
67
68*/
