12/**
13
14@brief GenericNodePropertyGradientLimiter - limits the nodal (finite-volume) gradient
15of target variable.
16
17If a property (saturation, solute concentration, etc...) is advected with second
18order accuarcy, some sort of slope limiting is required to avoid spurious oscillations. This
19objects computes the slope limiting factor phi using the MINMOD limiter for the nodal gradients
20that were computed employing the object NodePropertyGradient. This procedure
21is usually carreid out automatically int the various FiniteVolume<fT, dim>Visitor objects.
22The resulting gradient limiter is stored automatically in the CSP_PropertyDatabase
23using the CSP_Operands.
24
25The FiniteVolumeManager<fT, dim> and the FiniteVolume<fT, dim> classes are participants.
26
27The GenericNodePropertyGradientLimiter object collaborates with the FiniteVolume<fT, dim>AdvectionVisitor,
28the FiniteVolume<fT, dim>GradientVisitor, and the FiniteVolume<fT, dim>FluidPhaseVisitor
29
30A single GenericNodePropertyGradientLimiter object is automatically constructed when
31one of the above-mentioned visitors is constructed. The GenericNodePropertyGradientLimiter
32object should not be constructed from the main() file
33
34copyright (c) 2001 by Sebastian Geiger, Stephan K. Matthaei & Stephen G. Roberts
35
36*/

39
40 public:

42 GenericNodePropertyGradientLimiter( Model<dim>&, const char* region, std::vector<char*> prop_names );

47 void CalculateGenericNodalGradient();
