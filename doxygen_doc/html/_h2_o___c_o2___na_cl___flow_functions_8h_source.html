16/**
17 @brief H2O_CO2_NaCl_FlowFunctions: Saturation functions and fluid properties combined into flow functions for the H2O + CO2+ NaCl system
18
19 Use in conjunction with the PhaseStateFinder_H2O_CO2_NaCl for compositional simulation
20 in a mass-based transport framework. Plugs into a suitable FlowFunctionsModule
21 within the Colleoli class framework for a multiphase-multicomponent transport scheme.
22
23 Generate all relevant input values for transport scheme from SaturationFunctions and Fluid modules,
24 using the constitutive relationships specified therein.
25 Gets the fluid properties by interpolation from the Element nodes to its barycentre.
26
27 Expects that the water saturation, the fluid densities and viscosities to be placed on the element nodes,
28 while all material (k, phi, bcp etc.), and rocktype related parameters are placed on the element.
29
30 @note all parameters are weighted by the element thickness which is 1 for iso-dimensional elements.
31
32 @author Stephan Matthai
33 @date 7/1/2019
34
35 @discussion Phase state cannot be interpolated between nodes !
36 If we read the system state from the element,
37 in the case of an element-based phase state calculation, it may be
38 entirely different from that computed at the nodes and therefore,
39 we may try to fetch densities and viscosities which do not exist ?!
40
41*/

43// TODO: does the capillary diffusion multiplier need multiplication with density
