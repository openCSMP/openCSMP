62 @section motivation Motivation
63 "Halite" is legacy code from Thomas Driesner's developments for the H2O-NaCl system and is mostly used to build accurate lookup tables for the H2O-NaCl system, which are then actually used by CSMP++. It can be used instead of HaliteLookup but will be slower.
64
65 "Halite" computes various properties of the mineral halite (solid crystalline salt, NaCl) as a function of temperature and pressure [Celsius, Pa] according to the papers
66
67 Driesner T. and Heinrich C.A. (2007): The system H2O-NaCl. Part I: Correlation formulae for phase relations in temperature-pressure-composition space from 0 to 1000oC, 0 to 5000 bar, and 0 to 1 XNaCl. Geochimica et Cosmochimica Acta 71, 4880-4901.
68
69 Driesner T. (2007): The system H2O-NaCl. Part II: Correlations for molar volume, enthalpy, and isobaric heat capacity from 0 to 1000oC, 1 to 5000 bar, and 0 to 1 XNaCl. Geochimica et Cosmochimica Acta 71, 4902-4919.
70
71 @section usage Usage
72 Construct an instance of "Halite" with temperature (in C) and pressure (in Pa) as they exist in the code that is supposed to use "Halite" as constructor variables. "Halite" has an internal mechanism to make sure that it always uses the current values of temperature and pressure . Public member names should be self-explanatory, I hope.
73
74 @code
75 double t; // temperature [C] in user's application
76 double p; // pressure [Pa] in user's application
77 Halite halite(t,p);
78 ...
79 t = some_value;
80 p = some_other_value;
81 cout << halite.Density() << endl; // will return density at the new t and p conditions
82 @endcode
83
84 @section dependencies Dependencies
85 requires "ConvertConcentrationUnitsNaCl.h" to ensure consistent unit conversions
86
87 @section testing Testing
88 testing was done in the period before publication in 2007, prior to writing this documentation, no details are available anymore
89 */
