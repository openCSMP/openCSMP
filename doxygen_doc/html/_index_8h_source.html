21/** @brief Accessor for discretized physical variables
22
23 Link between PropertyDatabase and LocalVariableStorage.
24
25 @author S.K. Matthaei
26 @author P. Lang
27 @author S. Geiger
28 @author Stephen G. Roberts
29
30 @section motivation Motivation
31
32 Class encapsulates the three values that are required to retrieve a
33 CSP variable from a model based on an unstructured mesh: The Type()
34 distinguishes scalars, vectors and tensors from one-another since these
35 have different storage requirements.
36
37 The Place() specifies whether a variable is discretized on the nodes,
38 elements, faces or on constraint points. This has implications as to
39 how the variable is interpolated over the model domain.
40
41 The Index() is used internally by CSMP for housekeeping. It corresponds
42 to the number that the variable has in an alphabetically ordered
43 map of variables of the same type and placement, in the same model.
44
45
46 @section design Design Intent
47
48 Create a universal accessor for discretized physical variables in a
49 model.
50
51
52 @section applicability Applicability
53
54 Typically, a csmp::Index or Index object is initialized only once
55 before it is used as an accessor to variables in a model. The
56 initialization is done by the PropertyDatabase if so requested.
57
58 Index is applicable whereever the parallel structure csmp::Index is
59 applicable. The reason, why a class is present in addition to the
60 structure is that this allows to assign default values when indices
61 are constructed.
62
63
64 @section collaborations Collaborations
65
66 Index is known to the PropertyDatabase and all variable accessor
67 and mutator functions. It is used by PropertyHandle and Operand objects,
68 as well as Interrelations, Visitors and Algorithms to housekeep
69 currently used variables.
70
71
72 @section implementation Implementation
73
74 Both as struct csmp::Index and this class.
75
76
77 @section examples Application Examples
78
79 To get an Index for a variable of interest in order to perform
80 a computation, do the following:
81
82 @code
83 Index variable_key = prop_database.StorageKey("variable");
84 @endcode
85
86 @todo SKM: (3-F) complete scheme for compile-time variables
87
88*/
