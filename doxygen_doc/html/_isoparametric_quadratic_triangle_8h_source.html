20Quadratic triangular finite-element with local interpolation function

24 / s-axis (of local coordinate system)
25 3 /
26 o

28 6 o o 5

31 1 4 2
32
33
34The segment nodes are represented by IntegrationPoint variables. The local
35coordinates of the integration points are stored in the array objects 'ri'
36and 'si'.

38

42N1 = 0,0, N2 = 1,0, N3 = 0,1, N4 = 0.5,0, N5 = 0.5,0.5, N6 = 0, 0.5
