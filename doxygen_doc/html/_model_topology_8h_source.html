12/**
13 Model topology associates elements with regions and boundaries,
14 recording their names, element types, and their dimensionality.
15 This is important in model construction process.
16 The ModelTopology thus stores this "topologic" information, which
17 cannot be stored in the VSet.
18
19 In CSMP regions are model subdomains, just as boundaries and split boundaries. All of these can be stored in the ModelTopology.
20 They are distinguished only by their names. Thus, a Boundary either contains the string BOUNDARY in its name or has one of the standard names
21 for boundaries and or edges of box-shaped models (BOTTOM, TOP, LEFT, RIGHT, BACK, FRONT, IRREGULAR etc., EDGE1..EDGE12.
22 Likewise, SplitBoundary objects contain the string SPLITBOUNDARY in their name, typically separated by underscores from other more specific
23 parts of the name.
24
25 @attention It follows that the user has to assign appropriate names to the geometrical entities in their model that they want to become boundaries.
26
27 Model topology can also be used to perform a consistency check on the cells stored in the VSet.
28 Thus, it can check the cell numbering and the neighbor connectivity.
29 To some degree it can also fix such potential problems with the VSet.
30
31 When the model is supposed box-shaped, this is tested and potentially missing information is restored in collaboration with the VSet / VData and Box.
32 In this case it can deduce the correct BOX_BOUNDARY flags and assign them to the nodes.
33
34 When a model is created by ANSYS and output using the CSMP interface of ANSYS
35 the information needed to initialise the ModelToplogy class is contained in the '.asc' file.
36
37 @section motivation Motivation
38
39 ModelTopology was created to convey topological information from
40 an ANSYS model to CSMP so that corresponding named groups of elements
41 can be created and assigned specific material properties.
42
43 For this purpose, ModelTopology stores named maps of the element
44 IDs and types that make up specific model regions. By default, the
45 element names are the ANSYS element names as captured inside
46 the class ANSYS_ElementSpecifications. Functionality is there
47 in the public interface to convert these into CSMP names.
48
49 Since one does not always want to use all topological information and
50 or finite elements in a simulation, ModelTopology allows the user
51 to reduce the initial topology as, for instance, obtained from ANSYS's
52 meshing tools, to a few target regions - or element types, such as
53 only the volume elements. Several interfaces are provided for this
54 purpose.
55
56 @section structure Structure
57
58 ModelTopology assumes a complementary role to the VSet which
59 stores the connectivity between elements and their nodes. Thus, there
60 must always be a supporting VSet in order to build a Model.
61 When the ModelTopology is reduced to a subset of the original
62 model, corresponding operations must be performed on the VSet.
63
64 @author S.K. Matthaei
65 @date 2001
66
67 */
