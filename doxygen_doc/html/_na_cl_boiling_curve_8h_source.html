39 @section motivation Motivation
40
41 "NaClBoilingCurve" is legacy code from Thomas Driesner's developments for the H2O-NaCl system, and computes the vapor pressure of boiling NaCl liquid. It can be used standalone if only this information is needed. Otherwise, it is only used in the CSMP++ context for building accurate lookup tables for the H2O-NaCl system, which are significantly faster if the full system properties are needed.
42
43 Details of the underlying formulation can be found in
44
45 Driesner T. and Heinrich C.A. (2007): The system H2O-NaCl. Part I: Correlation formulae for phase relations in temperature-pressure-molefraction space from 0 to 1000oC, 0 to 5000 bar, and 0 to 1 XNaCl. Geochimica et Cosmochimica Acta 71, 4880-4901.
46
47 @section usage Usage
48 Construct an instance of "NaClBoilingCurve" with the temperature (in C) as constructor argument. "NaClBoilingCurve" has an internal mechanism to make sure that it always uses the current value of that temperature as they exist in your code. Public member names should be self-explanatory, I hope.
49
50 @code
51
52 double t(somevalue); // temperature [C] in user's application
53 ...
54 NaClBoilingCurve naclboil(t);
55 ...
56 // here, t may be updated
57 ...
58 cout << "new NaCl boiling pressure: " << naclboil.VaporPressure() << "Pa\n"; // compute and output vapor pressure on boiling curve [Pa] for new temperature
59
60 @endcode
61
62 @section issues Known issues
63
64 The underlying equations are valid only in a restricted temperature-pressure range; range checking and error handling has not yet been implemented
65
66 @section testing Testing

68 tested against CSP version (ok), which in turn was tested in the period before publication in 2007, prior to writing this documentation, no details are available anymore
69 */
