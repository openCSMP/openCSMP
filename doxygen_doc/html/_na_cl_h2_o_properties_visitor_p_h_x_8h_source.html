16 /*!
17 <!-- ================================================================== -->
18 <H1>NaClH2OPropertiesVisitorPHX</H1> <!-- ================================= -->
19 <!-- ================================================================== -->
20
21 <!-- ================================================================== -->
22 <H3>MOTIVATION</H3>
23 <!-- ================================================================== -->
24 In simulations of multiphase fluid flow involving heat and mass transport,
25 fluid properties are typically stored at nodes, and heat and mass transport
26 via diffusion and advection is done in a decoupled manner. This ultimately
27 means that after the diffusion and advection steps, the fluid phase state
28 may have changed and, even worse, very likely means that fluid and rock
29 are not in thermal equilibrium. NaClH2OPropertiesVisitorPHX will
30 perform a thermal equilibration between fluid and rock (using class
31 H2ONaClThermalEquilibrator) at a given pressure, total
32 enthalpy and salinity and update fluid properties for the equilibrated
33 state.
34
35 <p>
36 <!-- ================================================================== -->
37 <H3>DESIGN INTENT</H3>
38 <!-- ================================================================== -->
39 NaClH2OPropertiesVisitorPHX is an FEM_Visitor within the CSMP framework,
40 see also documentation there. It applies to nodes only.
41
42 <p>
43 <!-- ================================================================== -->
44 <H3>APPLICABILITY</H3>
45 <!-- ================================================================== -->
46 NaClH2OPropertiesVisitorPHX can be applied in simulations with pure H2O
47 fluids in combination with heat and mass transport. Simpler simulations
48 should use other tools in the CSMP++ package. A fundamental assumption is
49 that of thermal equilibrium between fluid and rock is requested, otherwise
50 using NaClH2OPropertiesVisitorPHX makes no sense at all.
51
52 NaClH2OPropertiesVisitorPHX also assumes that fluid properties are stored
53 on the nodes (i.e., it relates to a node-centered finite volume schemes for
54 solving the advection equations) and that rock properties discretized on the
55 element are uniquely defined such that their interpolated nodal values can
56 meaningfully be used (*** is that fully correct? ***).
57
58 <p>
59 <!-- ================================================================== -->
60 <H3>STRUCTURE</H3>
61 <!-- ================================================================== -->
62 <p>
63 <!-- ================================================================== -->
64 <H3>PARTICIPANTS</H3>
65 <!-- ================================================================== -->
66
67 NaClH2OPropertiesVisitorPHX uses H2ONaClThermalEquilibrator,
68 which itself calls a number of classes related to fluid properties, in
69 particular FluidLookup and the specialized classes for phases in the H2O
70 system (see documentation for FluidLookup etc.).
71

75 */

463 template<uint32_t dim>
464 inline double NaClH2OPropertiesVisitorPHX<dim>::EffectiveLiquidSaturationHalitePresent( double sat_liquid, double sat_vapor ) const
465 {
466 double seff;
467 double my_res_sl(res_sl*(sat_liquid+sat_vapor)),
468 my_res_sv(res_sv*(sat_liquid+sat_vapor));
469
470 // Changed JPW 26.5.2011
471 // seff = (sat_liquid - res_sl) / (sat_liquid + sat_vapor - res_sl - res_sv);
472 // seff = (sat_liquid - my_res_sl) / (sat_liquid + sat_vapor - my_res_sl - my_res_sv);
473 seff = (sat_liquid - my_res_sl) / (sat_liquid + sat_vapor - my_res_sl - my_res_sv);
474 if ( seff > static_cast<double>(1.0) ) return 1.0;
475 else if ( seff < static_cast<double>(0.0) ) return 0.0;
476 else return seff;
477
478 } // end EffectiveSaturation
479
480 template<uint32_t dim>
481 inline double NaClH2OPropertiesVisitorPHX<dim>::RelativePermeabilityLiquid( double sat_liquid, double sat_vapor ) const
482 {
483 double seff, sat_total(sat_liquid+sat_vapor);
484 double my_res_sl(res_sl*sat_total),
485 my_res_sv(res_sv*sat_total);
486
487 // Changed JPW 26.5.2011
488 seff = sat_total*(sat_liquid - my_res_sl) / (sat_liquid + sat_vapor - my_res_sl - my_res_sv);
489 if ( seff > static_cast<double>(sat_total) ) return sat_total;
490 else if ( seff < static_cast<double>(0.0) ) return 0.0;
491 else return seff;
492
493 } // end RelativePermeabilityLiquid
