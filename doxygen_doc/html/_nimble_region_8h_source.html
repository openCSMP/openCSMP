12/**
13 Flexible collection of Element and Node object pointers
14 to be used by the PDE_Integrator, which also requires access
15 to ranges of (perimeter) nodes.
16
17 NimbleRegion is a light (non-unique) version of Region that can grow or shrink,
18 retaining the knowledge of its perimeter.
19
20 Like Region, NimbleRegion keeps track of its perimeter, which
21 always includes a halo that comes about as all elements that
22 contain user-supplied nodes (and additional ones) will
23 be included into the contructed region.
24
25 The region is based on the STL vector and operated under a high-memory policy.
26 This means that the Update() and other functions retain previous vector storage
27 allocations, just resizing these vectors to zero when a reconstruction is performed,
28 to avoid costly memory allocations.
29 To delete both elements and the internal storage of the vectors, delete and create a new
30 NimbleRegion object.
31
32 @attention NimbleRegion does not have a name or properties of its own and
33 it is not managed by the RegionInterface,
34 create it using its constructor and manage it with DES or any other parallel algorithm.
35
36 @attention Grow(), Shrink() and ChangeShape() operations rely on the connectivity
37 between equidimensional elements and nodes.
38
39 @attention Thus far, Nimbleregion only works with linear elements.
40
41 Design specifications in detail: NimbleRegion for use in PDE_Integrators?
42
43 0. Must be a template with integral parameter uint32_t dim
44
45 1. Be a suitable plugin into the PDE_Integrator, meaning that it has the methods:
46
47 1.1 Must have a contructor that accepts iterators to node pointers
48 1.2 Should be able to change shape at low computational cost
49 1.3 Have the interfaces needed by the PDE_Integrator to function:
50 - Must be based on vectors,
51 - Know its perimeter nodes / have nodes sorted into interior and perimeter ranges
52 so that boundary conditions can be applied.
53
54 2. InterFace / task share with DES algorithm to convey update information.
55*/
