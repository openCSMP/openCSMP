260@author S.K. Matthaei
261@date 2008
262
263
264Generic transport module for CVFE computations on poly-element-type finite
265element (-finite-volume) meshes. Computations are done using an implicit
266or semi-implicit approach that is only weakly depedent on the
267grid-Courant number.
268
269A range of constructors allows to build the module for first-order,
270second-order conservative and non-conservative transport simulations
