13/**
14 Couples the nodes on the opposite sides of the InterFace,
15 using an operand (thermal or hydraulic conductivity) and the thickness attribute "thickness" for the interface.
16 (the latter needs to be defined as a separate variable with the placement INTER_FACE).
17
18 The coupling is created by emulating a thin-shell element (prism or hexahedron).
19 For this purpose the opposing collocated nodes are separated from one-another an amount equivalent to the thickness
20 before the coordinate matrix is initialised.
21
22 The separation of the nodes creates prism or hexahedral elements, from triangular and quadrilateral InterFace objects.
23 The InterFace normal is used in the construction of the edges of these elements.
24
25 @author SKM
26 @date 18/8/22
27*/
