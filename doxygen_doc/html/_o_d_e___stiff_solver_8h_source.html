11@brief Burlisch-Stoer solver for a stiff systemof ordinary differential equations.
12
13@section motivation Motivation
14
15A great variety of physical processes are best described by non-linear
16systems of ordinary differential equations (ODEs) which describe the
17change of the system. Typically, these ODEs can only be integrated
18(solved) numerically as is the case for rate-dependent
19chemical reactions. If the rate coefficients differ among the
20equations by many orders of magnitude, the systems are called stiff.
21The main numerical problem imposed by the 'stiffness' is that, for instance
22in a time-dependent system, some equilibria described by individual ODE
23equations are obtained very fast while other equations evolve very slowly.
24Coupling such different equations together, therefore requires very small time
25steps to limit the change in each step over periods where rapid changes occur.
26Large timesteps are however essential in periods of minor change to obtain a
27solution in a reasonable amount of time.
28
29Solution methods which provide
30the necessary adaptive timestepping are known as stiff ODE solvers, and
31the motivation for the design of the class ODE_StiffSolver is to
32make a robust solver of this kind available to CSP.
33
34
35@section Design Intent
36
37
38The class ODE_StiffSolver encapsulates a semi-implicit form of a
39Burlisch-Stoer method as described by Bader and Deuflhard (1983) into
40a code module which is also capable of the house keeping and analytical
41differentiation of the actual ordinary differential equations. Textfile
42input provides an interface for the definition and description
43of the system of equations in human-readable form. The equations are
44linked in a matrix scheme which uses LU decomposition and back substitution
45of the results after the inversion of the matrix in each timestep.
46The integration routine 'odeint' controls the timestep size using the
47cross derivatives of all of the individual ODEs. For this purpose, the
48derivatives are assembled into a Jacobian matrix. Additional methods are
49provided to change coefficients in individual equations without having
50to redine them. This capability is useful, for instance, if activities
51or surface area changes in an equilibration calculation.
52
53
54@section Applicability
55
56
57The class ODE_StiffSolver is useful only for relatively small systems
58of ODEs (<50 degrees of freedom). Runtime scales with number of ODEs
59which is also readily explained on a physical basis. Since the
60ODE coefficients will influence the condition number of the solution
61matrix, these must not differ from one-another by more than
62the numerical (double) precision. Otherwise the matrix will become singular.
63The solution speed also limits the applicability of the stiff ODE
64integration algorithm in serial application in a finite-element model.
65
66
67@section Implementation
68
69
70The implementation of the ODE solver stems from the second edition of
71Numerical Recipes in C by Press et al. 1996 (p. 742ff) which also provides
72detailed documentation of functions included. The original names of the functions
73which have been integrated as private methods of the class ODE_StiffSolver
74are derivs(), jacobn(), ludcmp(), lubksb(), simpr() pzextr(), odeint(), and
75stifbs(). Additional auxiliary methods manage storage in the peculiar
76numerical recipe way.
77
78The method implemented herein goes back to Bader, G. and Deuflhard, P. 1983,
79Numerische Mathematik 41, 373-398.
80

86represent individual OD equations in the stiff solver object.

105@section Application Examples
106
107
108The ODE_StiffSolver can be applied using its Solve() method inside of
109other CSP objects or it can be used as a stand-alone tool to solve
110non-linear ODEs. The system of equations is defined in a textfile
111starting with an underlined headline followed by a blank line, e.g.:
112
113@code
114carbonate - dissolution example
115===============================
116
117independent variables
118---------------------
119
120dependent variable definitions for which is solved for (aqueous, gaseous, and solid)
121------------------------------------------------------------------------------------
122OH_1m CO2_aq CC Ca_2p H_1p H2O_aq HCO3_1m
123
124equilibrium constants (in sequence of listed reactions, same number)
125--------------------------------------------------------------------
126KF=4.37e-2 KB1=3.4593938e-12 KB2=8.336811e+10 KB3=9727.4722
127
128reactions (odes) A + B -> C (K): dA/dt = -kf [A][B] + kf [C] / K
129-----------------------------------------------------------------
130OH_1m = -KF H_1p OH_1m + KB1 H2O_aq
131CO2_aq = -KF CO2_aq H2O_aq + KB2 HCO3_1m H_1p
132CC = -KF CC H_1p + KB3 HCO3_1m Ca_2p
133Ca_2p = KF CC H_1p + -KB3 HCO3_1m Ca_2p
134H_1p = KF CO2_aq H2O_aq + -KB2 HCO3_1m H_1p + -KF CC H_1p + KB3 HCO3_1m Ca_2p + -KF H_1p OH_1m + KB1 H2O_aq
135H2O_aq = KF H_1p OH_1m + -KB1 H2O_aq
136HCO3_1m = KF CO2_aq H2O_aq + -KB2 HCO3_1m H_1p + KF CC H_1p + -KB3 HCO3_1m Ca_2p
137@endcode
138
139Independent variables are specified next (such as constant coefficients).
140In this example, there are no independent variables. Again
141there is an underlined headline followed by the data and a blank line.
142
143The next block defines the names of the dependent variables in the
144equations (i.e., those variables which shall be calculated as a function
145of time). Importantly, no '+' or '-' signs must be used here since these
146symbols are reserved by the equation parser for algebraic operations.
147A similar block follows, specifying the numerical values of the
148equation coefficients using the assigment operator without blank space.
149In the example, forward and backward reaction rates are specified in
150terms of dissolution data and the equilibrium constants. This first
151order kinetic approach is described by Carl Steefel in the Min. Soc.
152America volume on reactive transport processes.
153
154A following 'reaction' block defines the actual ordinary differential
155equations in terms of the notation established above. Importantly, the
156ODEs must be listed in exactly the same order in which the dependent
157variables were defined before. There must be exactly one equation for each
158dependent variable and the stochiometry of the aqueous species/minerals
159determines the exponents and multipliers of the equation coefficients.
160This derives directly from the related mass-action expressions.
161
162Everything which follows after the blank line below the equation block
163is ignored. Here the user can insert comments and a discussion of the
164system he defined and its time-dependent behaviour.
165
166Of course, the described syntax can also be used to define arbitrary ODE
167systems other than sets of reaction equations.
168
169
170copyright (c) 1999 by Dr. Stephan K. Matthaei & Stephen G. Roberts
171
