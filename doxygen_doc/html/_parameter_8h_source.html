8/**
9 @brief Record that describes the physical variables that are stored on a model:
10
11 Stores variable name and notation (potential in correspondance with publications),
12 SI unit, type, range (simulaton-specific physically meaningful minimum and maximum value,

14
15 Usage can be used to tell a GUI which
16 parameters have to be input by the user, distinguishing them from
17 dependent (computed) values and/or the result of constitutive relation
18 calculations. However, there is no fixed terminology communicating this
19 yet.
20
21 Parameter records are managed by the PropertyDatabase class.
22
23 @author Stephan K. Matthai
24 @date 1994
25*/
