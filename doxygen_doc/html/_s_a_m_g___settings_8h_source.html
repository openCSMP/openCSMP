162/**
163
164@class SAMG_Settings SAMG_Settings "solver/SAMG_Settings.h"
165@author S.K. Matthaei
166@author S. Geiger
167@author G. Roberts
168@date 2001
169
170@section motivation Motivation
171
172Factoring out SAMG tuning parameter in a separate class so that they
173can be changed indepently of the solver object.
174
175
176@section design Design Intent
177
178SAMG_Settings objects store SAMG tuning parameter. These tuning parameter
179are divided into switches and their subswitches.
180
181Each switch can be accessed by its respective Get-method and its subswitches
182can be set using the respective Set-methods.
183
184Every Set-method checks if the input data conforms to the restrictions
185imposed by the SAMG solver. If the input value is invald, a domain_error
186exception is thrown.
187
188@warning Only the rules for the subswitch itself are checked! Interdependencies
189between subswitches are NOT checked! The user is responsible to guarantee that
190all subswitches together form a meaniful parametrization for the SAMG solver.
191*/
