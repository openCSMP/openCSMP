18@brief Subclass of Solver for linear algebra computations conducted with SAMG, the algebraic multigrid solver for systems of equation from SCAPOS, Fraunhofer, Germany.
19
20 Solves the linear algebraic system A x = b using the
21 algebraic multigrid solver DLL from SCAI, Fraunhofer Gesellschaft (St. Augustin, Bonn),
22 which can be obtained from SCAPOS.
23
24 Up to 2 istances of the DLL can be communicated with.
25 Use another instance of the solver if you have multiple PDEs that are
26 solved sequentially and you want to remember SAMG settings from step to step.
27
28 @section segFault Segmentation Fault on some linux based os
29
30 We have noticed invalid memory access when using dynamically allocated SAMG_Solver objects
31 and their calls to SAMG. To avoid that, use static(stack) instantiation. Right now we have no idea
32 why, but we're working on that...
33 @code
34 // i.e.:
35 SAMG_Settings settings;
36 settings.Set_napproach(2);
37 SAMG_Solver samgSolver(&settings);
38 PDE_Integrator<DIM,Region> pressure_diffusion(&samgSolver);
39 @endcode
40
41 @todo (1) Check line 254: is resetting res_in allowed if we use relative convergence
42 @todo (3) Convergence check 670: 679 check eps or fabs(eps)?
43 @todo (1) Look into runtime debug error when solving systems with vector as variable
44 @todo (3) Try mpl::is_volatile type trait to check whether they should manage the pointers they are supplied with in the constructor (B)
45
