9/**
10 Imports 3D SKUA models meshed with SKUA's FiniteElement mesher plugin and using an output procedure
11 created by Thomas Jerome (GMDK Inc.).
12
13 @attention if the variables "element number" and / or "node number" are in the variables file,
14 they will be initialised with the data from the original VSet.
15 This is important because CSMP's internal element and node numbering varies from run to run
16 since its mesh connectivity is based on pointers.
17
18 @note if elements are elimitated from the model in the build process, corresponding ID values dissappear.
19 However, the sequence of the element is not changed which means that "element number" can be collapsed
20 to achieve a consecutive range again.
21
22 @attention To rebuild model from CSMP native binary file do not use this SKUA model class,
23 the standard CSMP model. All functionality should be there.
24*/
