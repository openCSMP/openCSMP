11/// IMPORTANT: for legacy purposes, the transport class assumes that the supplied velocity has already been scaled
12/// to adjust for facet areas coming from the thickness attribute (LDE's). This is perhaps a little unintuitive,
13/// since any new user needs to know beforehand that this has to happen. The user should always provide the
14/// "real" velocity (not scaled) and the transport class should deal with thickness through internal scaling of its
15/// facet areas.
16/// This class calculates single phase velocity in its "de-scaled" form. No thickness factor is used. Thus, using this
17/// calculation with a problem containing LDE's and using legacy transport classes (e.g. NCFVT) requires
18/// an extra step of multiplication by a "thickness" attribute.
19///
20/// The class supports and will take advantage of Open MP by dividing the evaluation of the contributions equally among available
21/// threads.
22///
23/// -- Julian M. 26-09-2015
