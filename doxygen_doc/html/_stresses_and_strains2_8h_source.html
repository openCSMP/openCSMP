85/**
86
87class StressesAndStrains<2U> StressesAndStrains<2U> "mechanics/StressesAndStrains2.h"
88@author S.K. Matthaei
89@date 2000
90
91@section motivation Motivation
92
93Post-Processing: Use this operator to compute strains and stresses from nodal
94displacements using the matrix equation:
95
96
97{e} = [B]{d}
98
99
100In full form for two-dimensional analysis this is:
101
102
103e_x | d |
104 | - 0 |
105 | dx |
106 | |
107 | d | u
108{ e_y } = | 0 - | { }
109 | dy | v
110 | |
111 | d d |
112gamma_xy | - - |
113 | dy dx |
114
115
116or for the quadratic triangular element and the shape function derivatives at
117each node point:
118
119
120 | dN0dx 0 dN1dx 0 dN2dx 0 dN3dx 0 dN4dx 0 dN5dx 0 |
121B = | 0 dN0dy 0 dN1dy 0 dN2dy 0 dN3dy 0 dN4dy 0 dN5dy |
122 | dN0dx dN0dy dN1dx dN1dy dN2dx dN2dy dN3dx dN3dy dN4dx dN4dy dN5dx dN5dy |
123
124
125which must be computed at each node for higher order elements.
126
127The strains and stresses are computed at the elements integration points and
128then back extrapolated to the nodes. For this extrapolation linear functions
129are used which use the integration points as constraint points.
130
131In addition to the computation of the tensor variables 'strain' and 'stress'
132one has the option to compute the principal stresses and strains as well.
133The method then finds the vectors which correspond to the sigma1, 2, and 3
134directions which correspond to the Eigenvectors of the stress tensors.
135It also calculates the mean stress and the dilation as nodal properties.
136The Eigenvalues which correspond to the magnitudes of the principal
137strains and stresses are stored in the variables 'principal strain' and
138'principal stress'.
139
140The strains and stresses are averaged at the nodes among the elements
141which share each node since they diverge from element to element but
142VTK needs nodal properties. This has the disadvantage that stresses
143on material boundaries are somewhat unrealistic mixes.
144
145
146
147@section implementation Implementation
148
149Procedure: In several post-processing application cycles of this class
150object the following is performed:
151
1521. From the nodal displacements and the shape function derivatives, at the
153 integration points the strain and stress tensors at these locations are
154 computed (=optimal locations, see Barlow, 1977).
155
1562. Linearly extrapolate the strains back from the integration points
157 to the nodes. In this step, bilinear extrapolation is carried out
158 by the specific finite element used. Only linear variations in strain
159 over the element are supported at this stage. The nodal strains are
160 averaged among the adjacent elements since they diverge at these locations
161 from one-another.
162
1633. From the nodally averaged strains and stresses all other variables are
164 calculated.
165
166Steps 1 and 2 are accomplished in the first application cycle of the
167post-processing operator. The nodal averaging and following operations
168are done in a second cycle.
169*/
