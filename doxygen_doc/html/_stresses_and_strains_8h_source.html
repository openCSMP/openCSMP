84@class StressesAndStrains<3U> StressesAndStrains<3U> "mechanics/StressesAndStrains.h"
85@author S.K. Matthaei
86@date 2000
87
88@section motivation Motivation
89
90Post-Processing: Use this operator to compute strains and stresses from nodal
91displacements using the matrix equation:
92
93
94{e} = [B]{d}
95
96
97In full form for two-dimensional analysis this is:
98
99
100e_x | d |
101 | - 0 |
102 | dx |
103 | |
104 | d | u
105{ e_y } = | 0 - | { }
106 | dy | v
107 | |
108 | d d |
109gamma_xy | - - |
110 | dy dx |
111
112
113or for the quadratic triangular element and the shape function derivatives at
114each node point:
115
116
117 | dN0dx 0 dN1dx 0 dN2dx 0 dN3dx 0 dN4dx 0 dN5dx 0 |
118B = | 0 dN0dy 0 dN1dy 0 dN2dy 0 dN3dy 0 dN4dy 0 dN5dy |
119 | dN0dx dN0dy dN1dx dN1dy dN2dx dN2dy dN3dx dN3dy dN4dx dN4dy dN5dx dN5dy |
120
121
122which must be computed at each node for higher order elements.
123
124The strains and stresses are computed at the elements integration points and
125then back extrapolated to the nodes. For this extrapolation linear functions
126are used which use the integration points as constraint points.
127
128In addition to the computation of the tensor variables 'strain' and 'stress'
129one has the option to compute the principal stresses and strains as well.
130The method then finds the vectors which correspond to the sigma1, 2, and 3
131directions which correspond to the Eigenvectors of the stress tensors.
132It also calculates the mean stress and the dilation as nodal properties.
133The Eigenvalues which correspond to the magnitudes of the principal
134strains and stresses are stored in the variables 'principal strain' and
135'principal stress'.
136
137The strains and stresses are averaged at the nodes among the elements
138which share each node since they diverge from element to element but
139VTK needs nodal properties. This has the disadvantage that stresses
140on material boundaries are somewhat unrealistic mixes.
141
142
143
144@section implementation Implementation
145
146Procedure: In several post-processing application cycles of this class
147object the following is performed:
148
1491. From the nodal displacements and the shape function derivatives, at the
150 integration points the strain and stress tensors at these locations are
151 computed (=optimal locations, see Barlow, 1977).
152
1532. Linearly extrapolate the strains back from the integration points
154 to the nodes. In this step, bilinear extrapolation is carried out
155 by the specific finite element used. Only linear variations in strain
156 over the element are supported at this stage. The nodal strains are
157 averaged among the adjacent elements since they diverge at these locations
158 from one-another.
159
1603. From the nodally averaged strains and stresses all other variables are
161 calculated.
162
163Steps 1 and 2 are accomplished in the first application cycle of the
164post-processing operator. The nodal averaging and following operations
165are done in a second cycle.
166*/
