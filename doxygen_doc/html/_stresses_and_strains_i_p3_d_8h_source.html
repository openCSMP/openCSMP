72@class StressesAndStrainsIP3D<3U> StressesAndStrainsIP3D<3U> "mechanics/StressesAndStrainsIP3D.h"
73@author S.K. Matthaei
74@date 2000
75
76@section motivation Motivation
77
78Post-Processing: Use this operator to compute strains and stresses from nodal
79displacements using the matrix equation:
80
81
82{e} = [B]{d}
83
84
85In full form for two-dimensional analysis this is:
86
87
88e_x | d |
89 | - 0 |
90 | dx |
91 | |
92 | d | u
93{ e_y } = | 0 - | { }
94 | dy | v
95 | |
96 | d d |
97gamma_xy | - - |
98 | dy dx |
99
100
101or for the quadratic triangular element and the shape function derivatives at
102each node point:
103
104
105 | dN0dx 0 dN1dx 0 dN2dx 0 dN3dx 0 dN4dx 0 dN5dx 0 |
106B = | 0 dN0dy 0 dN1dy 0 dN2dy 0 dN3dy 0 dN4dy 0 dN5dy |
107 | dN0dx dN0dy dN1dx dN1dy dN2dx dN2dy dN3dx dN3dy dN4dx dN4dy dN5dx dN5dy |
108
109
110which must be computed at each node for higher order elements.
111
112The strains and stresses are computed at the elements integration points and
113then back extrapolated to the nodes. For this extrapolation linear functions
114are used which use the integration points as constraint points.
115
116In addition to the computation of the tensor variables 'strain' and 'stress'
117one has the option to compute the principal stresses and strains as well.
118The method then finds the vectors which correspond to the sigma1, 2, and 3
119directions which correspond to the Eigenvectors of the stress tensors.
120It also calculates the mean stress and the dilation as nodal properties.
121The Eigenvalues which correspond to the magnitudes of the principal
122strains and stresses are stored in the variables 'principal strain' and
123'principal stress'.
124
125The strains and stresses are averaged at the nodes among the elements
126which share each node since they diverge from element to element but
127VTK needs nodal properties. This has the disadvantage that stresses
128on material boundaries are somewhat unrealistic mixes.
129
130
131
132@section implementation Implementation
133
134Procedure: In several post-processing application cycles of this class
135object the following is performed:
136
1371. From the nodal displacements and the shape function derivatives, at the
138 integration points the strain and stress tensors at these locations are
139 computed (=optimal locations, see Barlow, 1977).
140
1412. Linearly extrapolate the strains back from the integration points
142 to the nodes. In this step, bilinear extrapolation is carried out
143 by the specific finite element used. Only linear variations in strain
144 over the element are supported at this stage. The nodal strains are
145 averaged among the adjacent elements since they diverge at these locations
146 from one-another.
147
1483. From the nodally averaged strains and stresses all other variables are
149 calculated.
150
151Steps 1 and 2 are accomplished in the first application cycle of the
152post-processing operator. The nodal averaging and following operations
153are done in a second cycle.
154*/
