119/**
120
121@class TwoPhaseVelocityAndVolumeFlux
122@author S.K. Matthai
123@date 2005
124
125@section motivation Motivation
126
127Post-Processing: Compute flow velocities and their magnitudes from the
128fluid pressure field, the conductivity, and the porosity of the medium.
129The flow velocities are computed at the element centers or integration
130points but they can be extrapolated to the nodes if this option is
131chosen. The variable names which are hardwired into this math operator
132are:
133
134@code
135"velocity" element vector
136"pore velocity" element vector
137"volume flux" element scalar
138"nodal velocity" node vector
139"nodal pore velocity" node vector
140"nodal volume flux" element scalar
141@code
142
143Those with a the "nodal" prefix are used only when the option for
144output to the nodes is chosen.
145
146
147@section implementation Implementation
148
149Procedure: In 2 post-processing application cycles of this class
150object the following is performed:
151
1521. From the nodal "fluid pressure" and the shape function derivatives,
153 the "fluid pressure gradient" at the element center (for elements with
154 linear interpolation functions), or at the integration points is
155 computed. For higher order elements these locations are optimal locations,
156 see Barlow, 1977).
157
1582. The product of the fluid pressure gradient, the conductivity, and the
159 porosity (in case of the interstitial velocity) and -1.0, gives the
160 flow velocity. The volume flux, as a scalar property, is given by
161 the magnitude of the Darcy velocity vector.
162
1633. If the properties shall be mapped to the nodes, they are linearly
164 extrapolated to these from the element center or the integration points.
165 In the case of linear elements, nodal velocities represent the
166 averages of adjacent elements. These are not weighted by element
167 area !
168
169 For quadratic elements, bilinear extrapolation is carried out
170 by the specific finite element used. Only linear variations in the velocity
171 over the element are supported at this stage. The nodal velocities are
172 averaged among the adjacent elements since they diverge at these locations
173 from one-another.
174
175Steps 1 and 2 are accomplished in the first application cycle of the
176post-processing operator. The nodal averaging and following operations
177are done in a second cycle.
178*/
