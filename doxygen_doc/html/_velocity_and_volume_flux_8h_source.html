13/**
14
15@brief Post-processes flow "velocity" & "volume flux" that are output as vector<double> and scalar variables, respectively
16upon request these properties are extrapolated to the nodes and averaged between adjacent elements.
17
18@author S.K. Matthai
19@date 2005
20
21@section motivation Motivation
22
23Post-Processing: Compute flow velocities and their magnitudes from the
24fluid pressure field, the conductivity, and the porosity of the medium.
25The flow velocities are computed at the element centers or integration
26points but they can be extrapolated to the nodes if this option is
27chosen. The variable names which are hardwired into this math operator
28are:
29
30@code
31"velocity" element vector
32"pore velocity" element vector
33"volume flux" element scalar
34"nodal velocity" node vector
35"nodal pore velocity" node vector
36"nodal volume flux" element scalar
37@endcode
38
39Those with a the "nodal" prefix are used only when the option for
40output to the nodes is chosen.
41
42
43@section implementation Implementation
44
45Procedure: In 2 post-processing application cycles of this class
46object the following is performed:
47
481. From the nodal "fluid pressure" and the shape function derivatives,
49 the "fluid pressure gradient" at the element center (for elements with
50 linear interpolation functions), or at the integration points is
51 computed. For higher order elements these locations are optimal locations,
52 see Barlow, 1977).
53
542. The product of the fluid pressure gradient, the conductivity, and the
55 porosity (in case of the interstitial velocity) and -1.0, gives the
56 flow velocity. The volume flux, as a scalar property, is given by
57 the magnitude of the Darcy velocity vector.
58
593. If the properties shall be mapped to the nodes, they are linearly
60 extrapolated to these from the element center or the integration points.
61 In the case of linear elements, nodal velocities represent the
62 averages of adjacent elements. These are not weighted by element
63 area !
64
65 For quadratic elements, bilinear extrapolation is carried out
66 by the specific finite element used. Only linear variations in the velocity
67 over the element are supported at this stage. The nodal velocities are
68 averaged among the adjacent elements since they diverge at these locations
69 from one-another.
70
71Steps 1 and 2 are accomplished in the first application cycle of the
72post-processing operator. The nodal averaging and following operations
73are done in a second cycle.
74
75*/
