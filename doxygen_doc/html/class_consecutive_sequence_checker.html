Detailed Description

integer sequences for whether they are consecutive.

Author
SKM
Date
10/12/2016
  1. Finds the max­i­mum and min­i­mum ele­ments in sequences
  2. Checks if the sequence length = max-min+1
  3. Checks if the sequence contains duplicates
  4. checks whether the elements of the sequence are consecutuve
Note
current implementation is restricted to size_t unsigned integers.
use Test_ConsecutiveSequenceChecker() to see verification of methods.
