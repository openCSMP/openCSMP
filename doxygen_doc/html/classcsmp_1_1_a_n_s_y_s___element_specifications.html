Detailed Description

Represents ANSYS element type specifications that are needed prior to model construction in order to identify corresponding element types in CSMP++.

Author
S.K. Matthai
Date
2003

Motivation

Relates the ANSYS finite element types to the generic finite element names that are used inside of CSP. Also additional diagnostics are obtained as to whether the element is a line, surface, or volume, and whether the element uses linear, quadratic or cubic basis functions. Furthermore the element can be queried for the number of neighbors and its minimum spatial dimension.

Implementation

ANSYS definitions of element types and their identification numbers are the following. They are only partially mapped to CSP and incorporated into enumerations to avoid the pollution of the csp namespace.

bool isoparametric,
uint32_t dim )
static

Returns the CSMP finite element type enum identifier that corresponds to the ANSYS type as identified by an integer identifier. The user needs to specify whether an isoparametric or globally interpolated element shall be returned because ANSYS elements can be converted into both.

Note however that ANSYS fits quadratic or cubic elements to the bounding curves. Thus, global interpolation will give incorrect results as it works only for straight-sided elements.

◆ MinimumSpatialDimension()

size_t csmp::ANSYS_ElementSpecifications::MinimumSpatialDimension ( const std::string & ANSYS_finite_element_type)
static

The element type used defines the spatial dimension of the model. It is indicative only of the minimum dimension since lines and surfaces can also exist in 3D space, which the name makes explicit.

Input Arguments

Method expects a string argument that contains the ANSYS element type to deduce the spatial dimension from.

Returns
size_t The minimum spatial dimension is returned as an unsigned integer ranging from 1(=1D) to 3(=3D).
