Detailed Description

Model for the construction from ANSYS ICEM 3D box-shaped and irregular meshes (including fracture-only DFN models). Additional "-regions.txt" file is required to select the mesh domains that shall be incorporated into the CSMP model.

Attention
if the variables "element number" and / or "node number" are in the variables file, they will be initialised with the data from the original VSet. This is important because CSMP's internal element and node numbering varies from run to run since its mesh connectivity is based on pointers.
Note
boundaries will always be created because they belong to intact CSMP models. This means that correspondingly named (see BOX_BOUNDARY or include string 'BOUNDARY' in their names ) surfaces must be present in the mesh.
