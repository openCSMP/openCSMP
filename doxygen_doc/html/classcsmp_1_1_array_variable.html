Detailed Description

Storage for an arbitrary number of variables with a single flag; array size is not predefined or dependent on model dimensions, but can be determined at runtime.

Author
P. Lang
Date
2012

In order to support arbitrary sized variables to be discretized in CSMP.

Usage

If used to read/store arrays from/on entities featuring a VariableStorage, the size of the ArrayVariable has to equal that specified in the variables file, since in the current version (9/4/2012) runtime changes regarding the PropertyDatabase and ArrayVariables are not supported.

To instantiate an ArrayVariable of arbitrary size:

ArrayVariable av; // 0 entries, flag set to Plain
ArrayVariable av(4, 10., DIRICH ); // 4 entries with value 10., flag set to Dirichlet
csmp::DIRICH
@ DIRICH
Definition CSMP_global_enumerations.h:64

When using ArrayVariable in Store/Read operations, we need to first create an instance of appropriate size, i.e. the same size as provided in the PropertyDatabase. A ctor which does exactly this is:

ArrayVariable av( "element array", model.Database() ); // size as specified in PropertyDatabase, values = 0., flag = plain

Again, the alternative would be to manually initiate the correct size. With an ArrayVariable of appropriate size, you may use functions like

model.InputPropertyValue( "element array", av );

Or something low level in the likes of

Index eaKey( model.Database().StorageKey("element array") );
for( vector<Element<3>*>::const_iterator it( model.Region("Model").CellsBegin() ); it != model.Region("Model").CellsEnd(); ++it )
(*it)->Read( eaKey, av );
