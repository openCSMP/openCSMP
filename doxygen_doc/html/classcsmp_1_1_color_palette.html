Detailed Description

Implementation of an RGB color table that is used in the creation of JPG output files. Used either to manage an array of RGBA values or as a runtime calculater of RGB colors.

16777216 (256^3) colors. This class should hold 256 RGB values of the template type // WHY 256????? It can take and give these values from the program or a file The palette can be composed with different saturations in different ranges of the spectrum. There is nothing it cannot do.

To serve OpenGL command: glColor4fv( array ); // or glColor4dv(a);
