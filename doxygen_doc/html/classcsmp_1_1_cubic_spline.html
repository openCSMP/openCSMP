Detailed Description

Implementation of a cubic spline using at least 3 constraint points / data values and 2 derivatives at the curve ends.

Note
A sufficiently large number of the datapoints need to be supplied to get a satisfactory spline, dependent on the curve represented by the data. Graph the spline curve first before using the results in other computations. The data for graphing can be obtained using the Out() function.

CubicSpine is used inside the experimental data-based saturation functions in the CSMP library found in the thmc directory.
