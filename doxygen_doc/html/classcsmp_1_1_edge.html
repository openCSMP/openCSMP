Detailed Description

template<uint32_t dim>
class csmp::Edge< dim >

Line "face" that knows its surface Face neighbors. Supports computations on the boundaries of 3D models. Variable placement is FACE. Can be a manifold.

Todo

design issue: edges should only exist only in 3D models because, only there, they can have Face neighbors.

remove templatisation, making this a 3D only entity
