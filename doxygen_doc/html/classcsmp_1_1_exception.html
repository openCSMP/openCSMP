Detailed Description

base class for CSMP-specific exception handling using an exception qualifier (CSMP_MESSAGE), an originator (the class and method from where the exception comes from, and a string that contains the message that describes what happened locally.

Note
no need to use a csmp::Exception if the case is well described by one of the standard exceptions.
