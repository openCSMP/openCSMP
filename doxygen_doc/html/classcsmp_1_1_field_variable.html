Detailed Description

template<size_t dim>
class csmp::FieldVariable< dim >

FieldVariable class for accessing distributed variables in the model.

FieldVariable represents a handle to a distributed variable (scalar, vector, tensor) in the model.

This class provides a clean interface for accessing variables that are distributed across the model hierarchy (Model > Region > Element > Node). It uses the PropertyDatabase to look up variable indices and LocalVariableStorage for actual variable access.

The class supports expression templates and operator overloading for mathematical operations.

Template Parameters
dimThe dimension of the model (2 or 3)

The FieldVariable provides access to variable values across a subdomain (e.g., Region, Boundary) and supports arithmetic operations and expression templates.

Template Parameters
dimSpatial dimension
CELLcell type used in the subdomain, i.e. Element for Region, Face for Boundary and InterFace for SplitBoundary
