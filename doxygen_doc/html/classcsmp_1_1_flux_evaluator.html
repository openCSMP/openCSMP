Detailed Description

template<uint32_t dim, template< uint32_t > class USER>
class csmp::FluxEvaluator< dim, USER >

Policy class that computes fluxes across finite-volume facets.

Part of trial implementation of Colleoli transport scheme.

Author

Version

Date

The transported variable on current and future time level is denoted as C0 and C1, respectively.

All interim results are stored on the model.

computes F = (A_i vD . n_i) and its products with the upstream C0 on all facets, also computes FV flux balances

Computes A_i vD . n_i for all facets and its product with the upstream concentrations. Stores 'facet flux' and 'facet flux concentration' product variables. Accumulates the flux balance and flux concentration balances in the corresponding node variables.

Attention
vD can be used directly as interstitial velocity since the FV is scaled by porosity
the thickness of lower-dimensional elements is taken into account
, assumes that the FV variables 'flux balance' and 'new concentration' were zeroed out before.

@tested OK SKM 17/8/19

template<uint32_t dim, template< uint32_t > class USER>
void csmp::FluxEvaluator< dim, USER >::FluxBalancesAtBoundary ( Node< dim > * const nd_ptr) const

computes flux balances on boundary FVs, using precomputed facet fluxes; volumetric balances are set to zero

From precomputed facet fluxes, FluxBalancesAtBoundary() computes:

  1. Nothing for FVs on the model boundary with Dirichlet concentration constraints.
  2. facet fluxes and flux balances of intact perimeter finite volumes that are not on the model boundary
  3. accumulation of facet flux-concentration products
  4. inflow if the the perimeter finite volume is truncated by the model boundary. This is determined from the AtBoundary() flag (flag!=NOT).

In summary, this method computes flux balances and concentration-facet flux products where possible, at sliced boundaries inflow (+) concentration products are stored to C1. At such boundaries the influx is found from the flux balance and the FV cell's concentration.

Attention
This method is only for perimeter nodes

void csmp::FluxEvaluator< dim, USER >::FluxBalancesFromFacetFluxes ( Node< dim > * const nptr) const

computes balance of transport variable fluxes from precomputed facet fluxes and transport variable

Computes and returns FV flux balance computed from pre-calculated thickness-weighted facet fluxes. The divergence of the volumetric flow is stored into the variable 'flux balance'. The volumetric flow * upstream concentration product is stored into 'new concentration'. Both, the flux balance and its product with concentration are stored on the node.

Attention
this method relies on precomputed facet fluxes.
