Detailed Description

template<uint32_t dim>
class csmp::GenericNodePropertyGradientLimiter< dim >

GenericNodePropertyGradientLimiter - limits the nodal (finite-volume) gradient of target variable.

If a property (saturation, solute concentration, etc...) is advected with second order accuarcy, some sort of slope limiting is required to avoid spurious oscillations. This objects computes the slope limiting factor phi using the MINMOD limiter for the nodal gradients that were computed employing the object NodePropertyGradient. This procedure is usually carreid out automatically int the various FiniteVolume<fT, dim>Visitor objects. The resulting gradient limiter is stored automatically in the CSP_PropertyDatabase using the CSP_Operands.

The FiniteVolumeManager<fT, dim> and the FiniteVolume<fT, dim> classes are participants.

The GenericNodePropertyGradientLimiter object collaborates with the FiniteVolume<fT, dim>AdvectionVisitor, the FiniteVolume<fT, dim>GradientVisitor, and the FiniteVolume<fT, dim>FluidPhaseVisitor

A single GenericNodePropertyGradientLimiter object is automatically constructed when one of the above-mentioned visitors is constructed. The GenericNodePropertyGradientLimiter object should not be constructed from the main() file
