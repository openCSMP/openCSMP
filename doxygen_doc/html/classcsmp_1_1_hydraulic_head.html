Pure virtual function that the user overrides to express the interrelation between variables mathematically. A more detailed description of this inheritance process is given in the introduction to the class above.

Implementation

Within Calculate() the user has access to Operands defined in the private data section of the Interrelation subclass. These Operands can be used in mathematical and logical expressions, or associated variables can be assigned to local variables of double, scalar, vector or tensor type. Please refer to the documentation of the Operand interface to learn about the overloaded operators.

Application Examples

To calculate local (element-restricted) interdependencies of physical variables inside of the CSP model.
