Detailed Description

template<uint32_t dim, class VARIABLE_SET>
class csmp::IntegralEquation< dim, VARIABLE_SET >

To build an equation add terms in the desired sequence into the LHS and RHS.

This class depends on the supply of INDEX keys for the transport problem, from the USER template parameter.
