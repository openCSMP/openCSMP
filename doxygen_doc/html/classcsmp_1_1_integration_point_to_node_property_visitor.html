Detailed Description

template<typename Var, uint32_t dim>
class csmp::IntegrationPointToNodePropertyVisitor< Var, dim >
Replaces value of FE-integratiion-point property 'a' with node property value 'b',
testing (for the case where all the node values are the same) whether the FE interpolation returns the same value.

Steps:

  • Visitor requires all nodes in the mesh to be numbered consecutively
  • the target node property has to be set to zero prior to the accumulation
  • Values are interpolated to nodes where these are accumulated
  • the nodal contributions are weighted by the distance of the element barycenter to each node (all weights are summed so that the absolute value can be rectified once the accumulation is complete).
