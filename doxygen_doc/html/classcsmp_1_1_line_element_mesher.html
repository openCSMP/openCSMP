Detailed Description

template<uint32_t dim>
class csmp::LineElementMesher< dim >

Line element mesher: collection of functions.

Creates polyline meshes that of an arbitrary dimension (like a spiral in 3D space). The meshes can contain duplicated nodes and INTERNAL boundaries.

Attention
Mesher does not assign BOX_BOUNDARY flags nor neighbor connectivity
Author
Stephan Matthai
extended to work with mulit-dimensional models by Roman Manasipov
Date
2002, 2012
