Detailed Description

Straight-sided, analytically integrated triangular finite element suspended in 3D space; linear element interpolation functions.

Date
2000
Author
S.K. Matthaei
Stephen G. Roberts
S. Geiger

Motivation

To carry out computations using linear triangular and tetrahedral elements with exact integration in which surfaces inside the tetrahedral mesh are represented by triangles oriented freely in space. This triangle has to be put into the FiniteElementManager in order to be accessible for computations.

Collaboration

The LinearTriangle3D collaborates with the 'Element' class within a bridge pattern proving polymorphic behaviour of the 'Element'.

Implementation

See CSMP User's guide for a full listing of shape functions and their derivatives.

◆ dN()

void csmp::LinearTriangle3D::dN ( DenseMatrix< DM_MIN > & B)
virtual

first derivatives of element interpolation functions

Reports the derivatives of the 3 linear element interpolation functions. These are stored into a matrix with m=rows=dimensions and n=cols=nodes of the triangle.

Input Arguments

The method uses the Element to get the nodal coordinates.

Parameters
BThe partial derivatives of the element interpolation functions are stored in the supplied matrix, where each node corresponds to a column of x, y, and z partial derivatives.

Implementation

Method uses an unconventional approach designed by Adrian Umpleby at Imperial College. The derivatives are found using normals, n, to planes which are perpendicular to the triangle and go through the 2 nodes opposite of the node for which the derivative is computed. Thus the normal faces the node, lies in the plane of the triangle and is equivalent in position to the height of the triangle. The formula for node 2 is:

dN1/dx = nx / n . -(p1 - p2) dN1/dy = ny / n . -(p1 - p2) dN1/dz = nz / n . -(p1 - p2)

Where . refers to the dot (scalar) product of the normal to plane through nodes 2 and 3, and (p1-p2) is the vector giving by the difference of the node points 12.

◆ IntegralNN()

void csmp::LinearTriangle3D::IntegralNN ( DenseMatrix< DM_MIN > & CE)
virtual

integral over interpolation functions

Computes the 'mass' matrix for the element for the case where the factor which is used to multiply the matrix with is constant on the element and can therefore be put in front of the integral.

Input Arguments

The coordinates of the Element are retrieved in order to calculate its area.

Parameters
CEThe mass matrix (nodes x nodes) is returned into the second argument of the method. This is a Meschach++ matrix which will be automatically resized if it has not got the correct dimensions.

Implementation

The mass matrix = Integral Ni Nj dx dy dz is explained in many FE text books. For instance in 'Groundwater Modeling by the Finite Element Method" AGU Monograph 13 by Jonathan Istok. The resulting matrix is output in its consistent form.

Application Examples

For example, to compute the element 'capacitance' matrix for transient fluid flow.

virtual

element interpolation functions at the point xzy

Computes the basis functions for this linear triangle element in 3D space at the point 'xyz' within the plane of the triangle.

Input Arguments

The method uses the data of the 'Element' to retrieve nodal coordinates, and the point location supplied as third method argument.

Parameters
NThe values of the 3 linear interpolation functions at the point 'xyz' are returned into the second method argument which is a Meschpp double vector.

Implementation

The interpolation functions are calculated using an approach by Adrian Umpleby (Imperial College) which is based on normals to planes through faces perpendicular to the triangles plane.
