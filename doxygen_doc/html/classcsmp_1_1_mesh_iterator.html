Detailed Description

template<uint32_t dim, template< uint32_t > class CELL>
class csmp::MeshIterator< dim, CELL >

Interator to perform a breadth-first traversal of contiguous mesh patch during its construction and then contain cell and node sets that can be used to iterate over the mesh tree.
