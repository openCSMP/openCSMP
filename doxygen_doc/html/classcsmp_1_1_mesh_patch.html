Detailed Description

template<uint32_t dim>
class csmp::MeshPatch< dim >

Contiguous mesh patch that can, but does not have to be integrated into a Model. The idea is to temporarily store parts of a mesh during rebuilding operations; Size info is used also to keep number information uptodate.

creates an interconnected element patch from the shared faces of the supplied elements; replicates nodes upon request, and returns perimeter nodes and size of patch

Creates an interconnected element patch from the shared faces of the supplied elements. There is no property storage associated with these elements from the start. The elements are rather barebone.

Parameters
input_elmtspairs of highest-dim elements that share a face that will be turned into a new lower-dimensional element
copy_nodesthe Elements already share nodes, but light copies of these are made when true
perimeter_node_ptrswhether copies are made or not, the method returns vector of pointers of the perimeter nodes of the new element patch

the number of new elements in the patch
