Detailed Description

template<uint32_t dim>
class csmp::MohrCoulombFailure< dim >

Using the current local stress state stored on the model in the variable "stress", this Interrelation subclass computes the failure criterion 'failure' performing a Mohr Coulomb analysis, but without consideration of the fluid pressure.

To apply this interrelation the following discretised variables need to be defined:

"stress", "mean stress", "cohesion", "failure".
