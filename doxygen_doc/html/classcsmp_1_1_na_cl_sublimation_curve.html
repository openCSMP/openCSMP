Detailed Description

Vapor pressure on the NaCl sublimation curve.

Author
Thomas Driesner, ETH Zuerich, thoma.nosp@m.s.dr.nosp@m.iesne.nosp@m.r@er.nosp@m.dw.et.nosp@m.hz.c.nosp@m.h

Motivation

"NaClSublimationCurve" is legacy code from Thomas Driesner's developments for the H2O-NaCl system, and computes the vapor pressure at sublimation (NaCl vapor / halite phase transition). It can be used standalone if only this information is needed. Otherwise, it is only used in the CSMP++ context for building accurate lookup tables for the H2O-NaCl system, which are significantly faster if the full system properties are needed.

Details of the underlying formulation can be found in

Driesner T. and Heinrich C.A. (2007): The system H2O-NaCl. Part I: Correlation formulae for phase relations in temperature-pressure-molefraction space from 0 to 1000oC, 0 to 5000 bar, and 0 to 1 XNaCl. Geochimica et Cosmochimica Acta 71, 4880-4901.

Usage

Construct an instance of "NaClSublimationCurve" with the temperature (in C) as constructor argument. "NaClSublimationCurve" has an internal mechanism to make sure that it always uses the current value of that temperature as they exist in your code. Public member names should be self-explanatory, I hope.

double t(somevalue); // temperature [C] in user's application
...
NaClSublimationCurve naclboil(t);
...
// here, t may be updated
...
cout << "new NaCl sublimation pressure: " << naclboil.VaporPressure() << "Pa\n"; // compute and output vapor pressure on sublimation curve [Pa] for new temperature

Known issues

The underlying equations are valid only in a restricted temperature-pressure range; range checking and error handling has not yet been implemented

Testing

csmp::NaClSublimationCurve::NaClSublimationCurve ( const double & externaltemperature)

custom constructor

Attention
Use only this conctructor. NaClSublimationCurve computes the vapor pressure of NaCl sublimation as a function of temperature. The latter is typically computed somewhere outside this class. By using const ref to that external variable as constructor argument, NaClSublimationCurve is able to decipher the current temperature value when being queried for the vapor pressure. Only this constructor is allowed to ensure that functionality, default constructor has been made private.
