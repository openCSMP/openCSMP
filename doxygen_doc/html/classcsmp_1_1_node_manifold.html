Detailed Description

template<uint32_t dim>
class csmp::NodeManifold< dim >

: a class that contains pointers to topologically (and most often also physically) collocated nodes. SplitBoundaries (node-matching standalone mesh patches connected by interface elements typically consist of NodeManifold objects.

Attention
the nodes on the perimeter of a SplitBoundary that terminates in a volume are not duplicated! - therefore they are not manifolds.
