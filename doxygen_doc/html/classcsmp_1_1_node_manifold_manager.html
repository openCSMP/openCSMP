Detailed Description

template<uint32_t dim>
class csmp::NodeManifoldManager< dim >

Policy of Model class for the management of manifolds that consist of multiplicated nodes.

Note
this class is not copy constructable because only a single instance is needed.
just storage management for manifolds; no targeted access.

Creates a node manifold from the 2 pointers to co-located nodes. Additional nodes can be added to it later.

Parameters
nodesreference to the primary storage of the nodes in the MeshManager
insidepointer to the node that will assumed to be on the INSIDE of the interface that that manifold is part of
outsideopposing yet collocated node in the manifold
manifold_typegeometric classifier of the new manifold, default is INTERFACE but may need to be revised if the node is at a model boudary or other.
Returns
an iterator to the new manifold stored in a colony in the NodeManifoldManager.
Attention
this method does not assign the nodes to the new manifold.; this must be done by calling Node::Assign( manifold ) after its successful creation which only happens on the return from this method.

scans for manifolds with a single Node only and deletes them

If there are single-node manifolds, their nodes are deconnected and the manifolds are deleted. Later, the manager is searched for the remaining null pointers and these are removed.
