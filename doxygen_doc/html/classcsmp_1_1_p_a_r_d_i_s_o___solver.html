Detailed Description

Interface to the direct PARDISO solver from the MKL library. Derived from Solver class, following CSMP's strategy design pattern for the solution of linear algebraic systems of equations.

Note
works only if there is access to the MKL library.

Some notes (SKM):

  • Since PARDISO is written in C, extern "C" declarations are needed for MKL functions. For example
  • good news: PARDISO is free for academic user, just register and download
  • parameters are rather similar to those used by SAMG, so much of the code can be copied from SAMG_Solver.cpp
  • C++ examples in mklroot\solverc\source\ directory
  • Intel MKL PARDISO is a direct sparse solver based on Parallel Direct Sparse Solver PARDISO*), an iterative sparse solver, and supporting sparse BLAS (level 1, 2, and 3) routines for solving sparse systems of equations, as well as a distributed version of Intel MKL PARDISO solver provided for use on clusters.
  • See PARDISO User's Guide and http://www.pardiso-project.org (Olaf Schenk, supercomputer center, Mano, Lugano)
  • PARDISO is defined in MKL_DOMAIN_PARDISO of the mkl.h header file.
  • is there another sparse direct solver? - mkl_dss.h
  • solver uses LaPack / libmkl_lapack.dylib
