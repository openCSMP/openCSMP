void csmp::SparseMatrix_Test::Test_PDE_IntegratorUseCases ( )

retests those specific methods that are used by PDE_Integrator

Tests specifically those methods that are used by PDE_Integrator:

  • Rows(), Cols()
  • Out()
  • Erase()
  • Resize()
  • Add( i, j, val ) - also checking whether nulled elements are eliminated
  • At( i, j ) vs. operator()(i,j)
  • Assign( i, j, val )
