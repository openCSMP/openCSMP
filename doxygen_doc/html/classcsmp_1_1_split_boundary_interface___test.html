Detailed Description

template<uint32_t dim>
class csmp::SplitBoundaryInterface_Test< dim >

SplitBoundaryInterface_Test unit test tests all functionality related to the creation and destruction of SplitBoundary objects. Refer to SplitBoundary_Test for tests of the functionality of the SplitBoundary itself.
