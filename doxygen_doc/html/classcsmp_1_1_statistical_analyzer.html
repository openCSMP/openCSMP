specify via ascii input file, the x-axis range of the histogram columns, i.e. the bin size

Function defines the bins for the histogram on the basis of the user input as specified in file which is read by this function. The file should contain the following information:

title number of bin-dilimiter values (integer) bin bound values (floating point) EOF

Example 'myfile.bins' 8 1.0e-5 2.0e-5 4.0e-5 6.0e-5 8.0e-5 1.0e-4 2.0e-4 6.0e-4 EOF

analyzes properties element by element interpolating variables to barycenter if necessary

Goes through all Regions of current Model and calculates the area/volume of the region with property values within the ranges defined in 'bins'. Normalizes the computed values by the total area/volume of the Region. Returns a map of bins and area/volume normalized values for each region using the region name as key / identifier.
