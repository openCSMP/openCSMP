Detailed Description

template<typename Item>
class csmp::UnionFind< Item >

Union-find algorithm. This data structure takes connections between two elements, and finds all of the connected components and their sizes. A "component" is represented by a single representative item.

See:

Tarjan, Robert Endre (1975). "Efficiency of a Good But Not Linear Set Union Algorithm". JACM. 22 (2): 215–225.
