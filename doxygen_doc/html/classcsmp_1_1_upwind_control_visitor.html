@changes changes Latest Changes

Motivation

Specialized visitor to define upwind nodes for CVFEM scheme.

Usage

To be used within the CVFEM scheme (Weis et al., Geofluids, 2014).

Calculates upwind nodes and store information in a matrix.
Calculates velocity and pore velocity vectors for graphical representations only!
csmp::store
void store(PropertyData &, size_t position, const csmp_var_type &)
storing the PropertyData data: store( data, i, makeScalar(ANY,0.) );

Dependencies

The functions are tailored for use in ExplicitFiniteVolumeTransportPHX. This visitor is needed in TwoPhaseTransportPHX and Upwind-PDE-operators.
