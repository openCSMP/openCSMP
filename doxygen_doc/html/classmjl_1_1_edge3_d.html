Edge3D & mjl::Edge3D::Rot ( const Point3D & ax,
bool normalize = false )

90o clockwise rotation of edge

computes the edge normal as the cross product between the edge and the edge defined by the rot-axis. The use can center the rotated unit normal=edge on the edge midpoint by using the center_edge boolean option

Warning
method works only for a normalized edge
