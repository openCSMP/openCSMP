◆ ManifoldType

enum class csmp::ManifoldType : int8_t
strong
Note
This classification is for NodeManifolds (topologically collocated Nodes) only)!
Not all of these classifiers apply to manifolds, like endpoint
NodeManifolds exist only at SplitBoundary objects
SplitBoundary objects exist only inside of models
since SplitBoundaries are surfaces, this is the highest dimension
Classification applies to all nodes within Manifold simultaneously (including intervening ones)
