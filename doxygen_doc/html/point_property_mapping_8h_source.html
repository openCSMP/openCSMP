16/**
17 Maps point properties from point clouds tagged with region names
18 to current 3D CSMP model.
19
20 Properties are mapped either to volumes and / or surfaces,
21 but the latter must be assigned last to avoid overwriting
22 of pre-assigned values.
23
24 After successful property assignment, the model is output to VTU for examination.
25 If appropriate the results can be safed to current CSMP binary.
26
27 The mapping involves both, volume/surface averaging, when multiple points
28 fall into the same element, interpolation using the SAMG solver when the data are sparse,
29 or nearest neighbor interpolation if where there are isolated element without property values.
30
31 See Mosser (2013, SPE 167629 -STU) for a full description of the implemented algorithm.
32
33 @todo TODO: implement averaging of the log10 of property value where these vary dramatically like permeability etc.
34
35 @author Lukas Mosser
36 @author Stephan Matthai
37
38*/
39
40void pointPropertyMapping( const std::string& model_name );
