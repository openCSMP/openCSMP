Detailed Description

template<uint32_t dim>
struct csmp::InterFaceParentElements< dim >

Vector of InterFace (higher-dim) Element - face idx pairs and Element co-located with InterFace (if present). For each InterFace we have a pair or Element pointer - face ID pairs 1) inner higher-dim element pointer 2) local face number of element face that is located at interface to outer element 3) outer higher-dim element pointer 4) local face number of element face that is located at interface to innner element 5) pointer to potential lower-dimensional intervening Element
