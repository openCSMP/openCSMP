class Newton\+Raphson\+Solve0$<$ dim, functor, real $>$}
This template class is an encapsulation of the one dimensional Newton\+Raphson iteration algorithm. It allows for calculating df twice at each iteration, or d2f, to increase the spead of convergance. It also can be used in situations with boundaries. The orignal source cand be viewed or downloaded \href{NewtonRaphson.h}{\texttt{here.}}~\newline

 The function do\+\_\+iteration, attempts to find the value of x, \+\_\+x\+\_\+converge, which solves the equation, (\+\_\+F.\texorpdfstring{$\ast$}{*}\+\_\+f(\+\_\+x\+\_\+converge) -\/ \+\_\+f\+\_\+solve) \texorpdfstring{$<$}{<} \+\_\+epsilon. ~\newline
 The second derivative d2f can optionally be supplied. If check\+\_\+boundary is set to true, then boundary solutions can be solved also. The member function do\+\_\+iteration, starts the iterative process. ~\newline
