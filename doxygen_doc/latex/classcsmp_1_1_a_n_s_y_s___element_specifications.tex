\doxysubsection{Detailed Description}
Represents ANSYS element type specifications that are needed prior to model construction in order to identify corresponding element types in CSMP++. 

\begin{DoxyAuthor}{Author}
S.\+K. Matthai 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2003
\end{DoxyDate}
\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
Relates the ANSYS finite element types to the generic finite element names that are used inside of CSP. Also additional diagnostics are obtained as to whether the element is a line, surface, or volume, and whether the element uses linear, quadratic or cubic basis functions. Furthermore the element can be queried for the number of neighbors and its minimum spatial dimension.\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
ANSYS definitions of element types and their identification numbers are the following. They are only partially mapped to CSP and incorporated into enumerations to avoid the pollution of the csp namespace. ~\newline
