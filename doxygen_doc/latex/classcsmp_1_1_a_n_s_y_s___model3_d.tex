\doxysubsection{Detailed Description}
\doxylink{classcsmp_1_1_model}{Model} for the construction from ANSYS ICEM 3D box-\/shaped and irregular meshes (including fracture-\/only DFN models). Additional "{}-\/regions.\+txt"{} file is required to select the mesh domains that shall be incorporated into the CSMP model.

\begin{DoxyAttention}{Attention}
if the variables "{}element number"{} and / or "{}node number"{} are in the variables file, they will be initialised with the data from the original \doxylink{classcsmp_1_1_v_set}{VSet}. This is important because CSMP\textquotesingle{}s internal element and node numbering varies from run to run since its mesh connectivity is based on pointers.
\end{DoxyAttention}
\begin{DoxyNote}{Note}
boundaries will always be created because they belong to intact CSMP models. This means that correspondingly named (see \doxylink{group___c_s_m_pglobal_enums_ga8e4421c3cd02f67e535bceb2dc74bfb6}{BOX\+\_\+\+BOUNDARY} or include string \textquotesingle{}BOUNDARY\textquotesingle{} in their names ) surfaces must be present in the mesh. 
\end{DoxyNote}
