\doxysubsection{Detailed Description}
Apply stresses to the boundaries of a three-\/dimensional geomechanic model. 

\begin{DoxyAuthor}{Author}
SKM 29/9/2014
\end{DoxyAuthor}
The stresses are entered via a \doxylink{classcsmp_1_1_stress_regime}{Stress\+Regime} object, but the variable \textquotesingle{}overburden pressure\textquotesingle{} storing the vertical stress Sv must be defined and initialised.

The \doxylink{classcsmp_1_1_andersonian_boundary_stress_visitor}{Andersonian\+Boundary\+Stress\+Visitor} accesses all \doxylink{classcsmp_1_1_boundary}{Boundary} objects, and resolves the boundary normal stress and shear stresses using the normals of the boundary \doxylink{classcsmp_1_1_face}{Face} objects which must be outward pointing.

In the corresponding calculations body forces must be enabled.

\begin{DoxyNote}{Note}
If a boundary is inclined or vertical, this is fine. In this case, the visitor takes the vertical variation in the boundary normal stress into account.
\end{DoxyNote}
Input variables are the stress state supplied by the \doxylink{classcsmp_1_1_stress_regime}{Stress\+Regime} object.

The visitor also computes the \doxylink{classcsmp_1_1_face}{Face} variables \textquotesingle{}normal stress\textquotesingle{} and \textquotesingle{}shear stress\textquotesingle{} on the visited boundaries. The nodal forces that it will apply are computed from these.

\begin{DoxyAttention}{Attention}
by default all forces that were previously assigned are zeroed first.

Confining stresses are always compressive and result inward pointing forces.

this visitor assumes that the far-\/field stress regime is Andersonian, i.\+e. one of the principal stresses is oriented perpendicular to the earth surface, i.\+e. that one of the principal stress axes is aligned with the vertical (Y)-\/axis of the CSMP model.
\end{DoxyAttention}
\begin{DoxyNote}{Note}
This visitor allows for a workaround for applying stress boundary conditions if one does not want to use the Neumann condition functionality of the \doxylink{classcsmp_1_1_p_d_e___integrator}{PDE\+\_\+\+Integrator}. 
\end{DoxyNote}
