\doxysubsection{Detailed Description}
Storage for an arbitrary number of variables with a single flag; array size is not predefined or dependent on model dimensions, but can be determined at runtime. 

\begin{DoxyAuthor}{Author}
P. Lang 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2012
\end{DoxyDate}
In order to support arbitrary sized variables to be discretized in CSMP.\hypertarget{classcsmp_1_1_upwind_control_visitor_usage}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{classcsmp_1_1_upwind_control_visitor_usage}
If used to read/store arrays from/on entities featuring a Variable\+Storage, the size of the \doxylink{classcsmp_1_1_array_variable}{Array\+Variable} has to equal that specified in the variables file, since in the current version (9/4/2012) runtime changes regarding the \doxylink{classcsmp_1_1_property_database}{Property\+Database} and Array\+Variables are not supported.
