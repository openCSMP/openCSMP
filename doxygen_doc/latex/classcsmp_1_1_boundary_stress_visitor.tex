\doxysubsection{Detailed Description}
\subsubsection*{template$<$uint32\+\_\+t dim$>$\newline
class csmp\+::\+Boundary\+Stress\+Visitor$<$ dim $>$}
\doxylink{classcsmp_1_1_boundary_stress_visitor}{Boundary\+Stress\+Visitor} accesses a \doxylink{classcsmp_1_1_boundary}{Boundary} object that must be a surface, computing nodal forces based on the normal and shear stresses applied to that \doxylink{classcsmp_1_1_boundary}{Boundary} element. If the boundary is inclined or vertical and body forces are enabled, the visitor takes the vertical variation in the boundary normal stress into account. 

\begin{DoxyAttention}{Attention}
this visitor assumes that the driving stresses are Andersonian, i.\+e. that one of the principal stress axes is aligned with the vertical (Y)-\/axis of the model.
\end{DoxyAttention}
\begin{DoxyNote}{Note}
This visitor allows for a workaround for applying stress boundary conditions if one does not want to use the Neumann condition functionality of the \doxylink{classcsmp_1_1_p_d_e___integrator}{PDE\+\_\+\+Integrator}.
\end{DoxyNote}
Input are the \doxylink{classcsmp_1_1_face}{Face} variables \textquotesingle{}normal stress\textquotesingle{} and \textquotesingle{}shear stress.\textquotesingle{} The nodal forces are computed from these.

Use this, for instance to compute and apply overburden stresses.

\begin{DoxyAttention}{Attention}
by default all forces that were previously assigned are zeroed first.

compressive (inward pointing) stresses are positive.

this visitor assumes that the far-\/field stress regime is Andersonian, i.\+e. one of the principal stresses is oriented perpendicular to the earth surface.
\end{DoxyAttention}
