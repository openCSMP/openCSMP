\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
\doxylink{classcsmp_1_1_brine}{Brine} is legacy code from Thomas Driesner\textquotesingle{}s developments for the H2\+O-\/\+Na\+Cl system, but it is REQUIRED in the CSMP context. There, it is essential to build accurate lookup tables for the H2\+O-\/\+Na\+Cl system, which are then actually used by CSMP. As long as we don\textquotesingle{}t distribute the lookup tables per se for the various platforms, the \doxylink{classcsmp_1_1_brine}{Brine} legacy will remain in CSMP.

\doxylink{classcsmp_1_1_brine}{Brine} computes the properties of H\textsubscript{2}O-\/\+Na\+Cl fluids as a function of temperature-\/pressure-\/composition \mbox{[}Celsius, bar, mole fraction Na\+Cl\mbox{]} , according to the paper

Driesner T. (2007)\+: The system H2\+O-\/\+Na\+Cl. Part II\+: Correlations for molar volume, enthalpy, and isobaric heat capacity from 0 to 1000oC, 1 to 5000 bar, and 0 to 1 XNa\+Cl. Geochimica et Cosmochimica Acta 71, 4902-\/4919.\hypertarget{classcsmp_1_1_upwind_control_visitor_usage}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{classcsmp_1_1_upwind_control_visitor_usage}
Construct an instance of "{}\+Brine"{} with the temperature (in C), Pressure (Pa) and Na\+Cl Concentration (mass fraction) that live in your code part as constructor arguments. "{}\+Brine"{} has an internal mechanism (via const\&) to make sure that it always uses the current values of temperature, pressure, and composition that you have calculated externally. Public member names should be self-\/explanatory. Don\textquotesingle{}t experiment with making private memebrs public as that will almost inevitably lead to wrong results!

\begin{DoxyAttention}{Attention}
Use only this conctructor. \doxylink{classcsmp_1_1_brine}{Brine} computes thermodynamic properties of H2\+O-\/\+Na\+Cl solutions as a function of temperature, pressure, and composition. These governing parameters are typically computed somewhere outside this class. By using const refs to those external variables as constructor argument, \doxylink{classcsmp_1_1_brine}{Brine} is able to decipher their current values when being queried for fluid properties. Only this constructor is allowed to ensure that functionality, default constructor has been made private. 
\end{DoxyAttention}
