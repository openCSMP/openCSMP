\subsubsection*{template$<$uint32\+\_\+t dim$>$\newline
class csmp\+::\+Brittle\+Failure\+Visitor$<$ dim $>$}
Evaluates (brittle) shear and tensile failure criteria that are output to the element integration points.

Input variables\+:
\begin{DoxyItemize}
\item friction angle
\item cohesion (scalar)
\item stress (tensor) = Cartesian stress
\item fluid pressure (if this variable is not specified its value is assumed to be zero)
\item Biot coefficient
