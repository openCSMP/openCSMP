This class implements the classic condensed row storage format for sparse matrices that is common to many linear algebra packages. This matrix is always square.

\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
If nnu denotes the number of rows (variables), the non-\/zero entries of the i-\/th row (1 ≤ i ≤ nnu) are stored in \doxylink{classcsmp_1_1_compressed_row_matrix_a9fc00fc9121ab81b0b0eac3e967a5d56}{a(j)} where

\doxylink{classcsmp_1_1_compressed_row_matrix_a1611d70fbf30774e9cdfc3b691c174fc}{ia(i)} ≤ j ≤ ia(i+1)-\/1.

In particular, according to the above-\/mentioned convention about the location of the diagonal element, \doxylink{classcsmp_1_1_compressed_row_matrix_a9fc00fc9121ab81b0b0eac3e967a5d56}{a(ia(i))} contains the diagonal entry of row i. Note that \doxylink{classcsmp_1_1_compressed_row_matrix_a1611d70fbf30774e9cdfc3b691c174fc}{ia(1)} = 1 and ia(nnu+1) = nna+1 where nna denotes the total number of matrix entries stored.

ia, ja define the order of the off-\/diagonal elements in the solution matrix storage vector a (that holds them row by row).

The pointer vector ja has to be defined so that \doxylink{classcsmp_1_1_compressed_row_matrix_a8d7b28ce3d544e34bbb47283eaef3907}{ja(j)} (1 ≤ j ≤ nna) equals the original matrix’ column index of \doxylink{classcsmp_1_1_compressed_row_matrix_a9fc00fc9121ab81b0b0eac3e967a5d56}{a(j)}, ie, \doxylink{classcsmp_1_1_compressed_row_matrix_a9fc00fc9121ab81b0b0eac3e967a5d56}{a(j)} corresponds to the variable u(ja(j)). In particular, since \doxylink{classcsmp_1_1_compressed_row_matrix_a9fc00fc9121ab81b0b0eac3e967a5d56}{a(ia(i))} contains the diagonal entry of row i, we have \doxylink{classcsmp_1_1_compressed_row_matrix_a8d7b28ce3d544e34bbb47283eaef3907}{ja(ia(i))}=i.

While, in the compressed row format, all diagonal entries must be stored, off-\/diagonal entries are only stored if they are non-\/zero. ~\newline
