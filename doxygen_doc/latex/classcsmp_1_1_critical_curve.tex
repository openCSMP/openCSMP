 Although "{}\+Critical\+Curve"{} is legacy code from Thomas Driesner\textquotesingle{}s developments for the H2\+O-\/\+Na\+Cl system, it is REQUIRED in the CSMP++ context. There, it is essential to build accurate lookup tables for the H2\+O-\/\+Na\+Cl system, which are then actually used by CSMP++. As long as we don\textquotesingle{}t distribute the lookup tables per se for the various platforms, the "{}\+Critical\+Curve"{} legacy will remain in CSMP++. ~\newline
