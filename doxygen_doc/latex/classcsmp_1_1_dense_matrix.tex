class csmp\+::\+Dense\+Matrix$<$ mn\+\_\+max $>$}
Fixed-\/size full-\/storage matrix template as a workhorse for finite element integral computations and accumulation of contributions to the global solution matrix.

Involves\+: M = dense matrix, v = vector, \+\_\+T = transposed,

Interoperable with with basic CSMP variable types T = tensor matrix(dim,dim), default vector is a column vector (v = \{ c0,c2..cn-\/1 \}, vc = \doxylink{classvector}{vector(dim)} )
