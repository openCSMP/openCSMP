\doxysubsection{Detailed Description}
PROPS and several other specifications from the RUNSPECS file record. 

\begin{DoxyAuthor}{Author}
R. Manasipov 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2014-\/2015
\end{DoxyDate}
ASCII file interface to read corner point grid from ( \texorpdfstring{$\ast$}{*}.GRDECL, \texorpdfstring{$\ast$}{*}.grdecl ) file. In order to build a native CSMP \doxylink{classcsmp_1_1_model}{Model} the provided grid information is assigned to \doxylink{classcsmp_1_1_v_set}{VSet} and \doxylink{classcsmp_1_1_model_topology}{Model\+Topology} objects. The regions that are constructed by default are\+: \% regions which include all the cells MATRIX MATRIX\+\_\+\+ACTIVE MATRIX\+\_\+\+INACTIVE \% and specific fault regions

In addition to grid information the properties such as\+: \textquotesingle{}permeability\textquotesingle{}, \textquotesingle{}porosity\textquotesingle{}, \textquotesingle{}pressure\textquotesingle{}, \textquotesingle{}saturation\textquotesingle{} can be readed as well. User is able to control property type and placement. For example one can create tensor or scalar permeability variables or to place \textquotesingle{}pressure\textquotesingle{} at the nodes or elements.
