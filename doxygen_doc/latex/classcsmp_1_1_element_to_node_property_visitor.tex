Steps\+:


\begin{DoxyItemize}
\item \doxylink{classcsmp_1_1_visitor}{Visitor} requires all nodes in the mesh to be numbered consecutively
\item the target node property has to be set to zero prior to the accumulation
\item Values are interpolated to nodes where these are accumulated
\item the nodal contributions are weighted by the distance of the element barycenter to each node (all weights are summed so that the absolute value can be rectified once the accumulation is complete).
