\doxysubsection{Detailed Description}
base class for CSMP-\/specific exception handling using an exception qualifier (\doxylink{namespacecsmp_a6a7cd0f08693c4632eea521f4ab13cb8}{CSMP\+\_\+\+MESSAGE}), an originator (the class and method from where the exception comes from, and a string that contains the message that describes what happened locally. 

\begin{DoxyNote}{Note}
no need to use a \doxylink{classcsmp_1_1_exception}{csmp\+::\+Exception} if the case is well described by one of the standard exceptions.
\end{DoxyNote}
