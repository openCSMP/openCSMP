\doxysubsection{Detailed Description}
\subsubsection*{template$<$uint32\+\_\+t dim$>$\newline
class csmp\+::\+Face\+Construction\+Data$<$ dim $>$}
Container of pairs of pointers to \doxylink{classcsmp_1_1_element}{Element} objects juxtaposed along a shared face identified by its local face number. Used in the construction of \doxylink{classcsmp_1_1_boundary}{Boundary} and \doxylink{classcsmp_1_1_split_boundary}{Split\+Boundary} objects. 

The juxtaposed elements must have the same dimension as the model. The first element in the pair is the inside one and the second one the outside one. Material values identify which regions they belong to. There is also a \doxylink{classcsmp_1_1_face}{Face} or \doxylink{classcsmp_1_1_inter_face}{Inter\+Face} patch number used to identify the new modelsubdomain that will be created with the help of \doxylink{classcsmp_1_1_face_construction_data}{Face\+Construction\+Data}.
