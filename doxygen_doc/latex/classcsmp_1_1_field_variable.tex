\subsubsection*{template$<$size\+\_\+t dim$>$\newline
class csmp\+::\+Field\+Variable$<$ dim $>$}
\doxylink{classcsmp_1_1_field_variable}{Field\+Variable} class for accessing distributed variables in the model. 

\doxylink{classcsmp_1_1_field_variable}{Field\+Variable} represents a handle to a distributed variable (scalar, vector, tensor) in the model.

This class provides a clean interface for accessing variables that are distributed across the model hierarchy (\doxylink{classcsmp_1_1_model}{Model} \texorpdfstring{$>$}{>} \doxylink{classcsmp_1_1_region}{Region} \texorpdfstring{$>$}{>} \doxylink{classcsmp_1_1_element}{Element} \texorpdfstring{$>$}{>} \doxylink{classcsmp_1_1_node}{Node}). It uses the \doxylink{classcsmp_1_1_property_database}{Property\+Database} to look up variable indices and \doxylink{classcsmp_1_1_local_variable_storage}{Local\+Variable\+Storage} for actual variable access.

The class supports expression templates and operator overloading for mathematical operations.


\begin{DoxyTemplParams}{Template Parameters}
{\em dim} & The dimension of the model (2 or 3)\\
\hline
\end{DoxyTemplParams}
The \doxylink{classcsmp_1_1_field_variable}{Field\+Variable} provides access to variable values across a subdomain (e.\+g., \doxylink{classcsmp_1_1_region}{Region}, \doxylink{classcsmp_1_1_boundary}{Boundary}) and supports arithmetic operations and expression templates.


\begin{DoxyTemplParams}{Template Parameters}
{\em dim} & Spatial dimension \\
\hline
{\em CELL} & cell type used in the subdomain, i.\+e. \doxylink{classcsmp_1_1_element}{Element} for \doxylink{classcsmp_1_1_region}{Region}, \doxylink{classcsmp_1_1_face}{Face} for \doxylink{classcsmp_1_1_boundary}{Boundary} and \doxylink{classcsmp_1_1_inter_face}{Inter\+Face} for \doxylink{classcsmp_1_1_split_boundary}{Split\+Boundary} \\
\hline
\end{DoxyTemplParams}
