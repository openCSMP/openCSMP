\doxysubsection{Detailed Description}
extension of \doxylink{classcsmp_1_1_element}{Element} interface for FV computations for all elements we need to test\+:


\begin{DoxyItemize}
\item \texorpdfstring{$\ast$}{*}build the element by applying the following transformation to the orginal reference element\+:
\begin{DoxyItemize}
\item Translate(-\/3,0,0)
\item Rotate(\+N0, 40degrees)
\item Shear(\+N0, N1, 35degrees)
\end{DoxyItemize}
\item \texorpdfstring{$\ast$}{*}facet and sector weights are as calculated in Rhino
\begin{DoxyItemize}
\item \texorpdfstring{$\ast$}{*}normals are correct
\item \texorpdfstring{$\ast$}{*}\+Facet\+Area() and Sector\+Volume() give correct results
\item \texorpdfstring{$\ast$}{*}\+Sector volumes add to volume of element
\item \texorpdfstring{$\ast$}{*}projection of vector variable in physical space gives the same result as the more efficient projection (Parametric\+Projection)
\item (checked)interpolation functions at sector and facet integration points are correct
\item (checked)Property\+Values are interpolated to the correct integration points
\item (used in reimpl of Facet\+Area heavily)rst to xyz conversion is correct 
\end{DoxyItemize}
\end{DoxyItemize}
