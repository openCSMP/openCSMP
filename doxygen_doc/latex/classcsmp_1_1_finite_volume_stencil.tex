\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
Class provides a whole set of functionality, related to construction of the node-\/centered FV virtual cells for realisation of the CVPEM in CSP.

Tesarius\+: sector -\/ sector part of the finite element (FE), attributed to the FE node. Number of sectors corresponds to the number of nodes. Sector is a topological hexahedron and is defined in physical and parametric spaces of the FE. Physical and parametric spaces of the FE are related by the mapping, characterized by Jacobian transformation.

facet -\/ four-\/side face inside the FE, dividing it to volumetric sectors.

Other set of methods here is providing accessors for the stencil dynamic data\+: integration points in the parametric space of the finite element, integration weights, normals and correction multiplies for unification of the parametric paces of different elements.\hypertarget{classcsmp_1_1_visitor_applicability}{}\doxysubsection{\texorpdfstring{Applicability}{Applicability}}\label{classcsmp_1_1_visitor_applicability}
Class is applicable to any FE model, containing isoparametric linear elements. It can work on the mono-\/ and poly-\/element type meshes, containing tetrahedrons, hexahedrons, prisms and pyramids.\hypertarget{classcsmp_1_1_solver_participants}{}\doxysubsection{\texorpdfstring{Participants}{Participants}}\label{classcsmp_1_1_solver_participants}
Gets it data from Integration\+Points\+And\+Weights.\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
Class provides facet / sector integration methods for finite volumes associated with specific finite elements. For tabulation of the points and weights if uses class \doxylink{classcsmp_1_1_f_v___integration_points_and_weights}{FV\+\_\+\+Integration\+Points\+And\+Weights} ().
