\subsubsection*{template$<$uint32\+\_\+t dim$>$\newline
class csmp\+::\+Fracture$<$ dim $>$}
The \doxylink{classcsmp_1_1_fracture}{Fracture} class is a \doxylink{class_fracture_tip}{Fracture\+Tip} Manager. It is responsible for the creation of fracture tips relevant to a split boundary, and their updating when a \doxylink{class_fracture_tip}{Fracture\+Tip} propagates. The \doxylink{classcsmp_1_1_fracture}{Fracture} class has 1 Fundamental requirement for creation 1) A split boundary. 

This class provides a tool to model fractures and accurately handle fracture mechanics.

The \doxylink{classcsmp_1_1_fracture}{Fracture} class manages two fundamental data types 1) A collection of Tip\+Nodes. 2) A collection of Fracture\+Tips.

Construction involves\+: Identifying Tip Nodes of the splitboundary \& constructing an associated \doxylink{class_fracture_tip}{Fracture\+Tip}.

Propagation involves\+: A modification (without deletion/reconstruction) of the fracture tips and their associated tip nodes.

\begin{DoxyAttention}{Attention}
From a User Perspective! When advancing to a new time step, the user must set run Set\+Old\+Coordinates\+To\+Current\+Tip() in order to calibrate the old tip coordinate of all \doxylink{class_fracture_tip}{Fracture\+Tip} objects (this ensures propagation velocity is calculated correctly every time step) 
\end{DoxyAttention}
