\doxylink{classcsmp_1_1_h2_o___c_o2___na_cl___flow_functions}{H2\+O\+\_\+\+CO2\+\_\+\+Na\+Cl\+\_\+\+Flow\+Functions}\+: Saturation functions and fluid properties combined into flow functions for the H2O + CO2+ Na\+Cl system. 

Use in conjunction with the \doxylink{classcsmp_1_1_phase_state_finder___h2_o___c_o2___na_cl}{Phase\+State\+Finder\+\_\+\+H2\+O\+\_\+\+CO2\+\_\+\+Na\+Cl} for compositional simulation in a mass-\/based transport framework. Plugs into a suitable Flow\+Functions\+Module within the Colleoli class framework for a multiphase-\/multicomponent transport scheme.

Generate all relevant input values for transport scheme from Saturation\+Functions and \doxylink{classcsmp_1_1_fluid}{Fluid} modules, using the constitutive relationships specified therein. Gets the fluid properties by interpolation from the \doxylink{classcsmp_1_1_element}{Element} nodes to its barycentre.

Expects that the water saturation, the fluid densities and viscosities to be placed on the element nodes, while all material (k, phi, bcp etc.), and rocktype related parameters are placed on the element.
