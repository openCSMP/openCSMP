\doxysubsection{Detailed Description}
Properties of the mineral halite (crystalline Na\+Cl) as a function of temperature and pressure.

\href{mailto:thomas.driesner@erdw.ethz.ch}{\texttt{thomas.\+driesner@erdw.\+ethz.\+ch}}\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
"{}\+Halite"{} is legacy code from Thomas Driesner\textquotesingle{}s developments for the H2\+O-\/\+Na\+Cl system and is mostly used to build accurate lookup tables for the H2\+O-\/\+Na\+Cl system, which are then actually used by CSMP++. It can be used instead of \doxylink{classcsmp_1_1_halite_lookup}{Halite\+Lookup} but will be slower.

"{}\+Halite"{} computes various properties of the mineral halite (solid crystalline salt, Na\+Cl) as a function of temperature and pressure \mbox{[}Celsius, Pa\mbox{]} according to the papers

Driesner T. and Heinrich C.\+A. (2007)\+: The system H2\+O-\/\+Na\+Cl. Part I\+: Correlation formulae for phase relations in temperature-\/pressure-\/composition space from 0 to 1000oC, 0 to 5000 bar, and 0 to 1 XNa\+Cl. Geochimica et Cosmochimica Acta 71, 4880-\/4901.

Driesner T. (2007)\+: The system H2\+O-\/\+Na\+Cl. Part II\+: Correlations for molar volume, enthalpy, and isobaric heat capacity from 0 to 1000oC, 1 to 5000 bar, and 0 to 1 XNa\+Cl. \begin{DoxyAttention}{Attention}
Use only this conctructor. \doxylink{classcsmp_1_1_halite}{Halite} computes halite properties as a function of temperature and pressure. These are typically computed somewhere outside this class. By using const refs to those external variables as constructor argument, \doxylink{classcsmp_1_1_halite_liquidus}{Halite\+Liquidus} is able to decipher their current values when being queried for halite properties. Only this constructor is allowed to ensure that functionality, default constructor has been made private. 
\end{DoxyAttention}
