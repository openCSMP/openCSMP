Maartje Boons \& Sally Benson (Stanford visit May 16-\/23, 2019), model for a layered composite. Material parameters are inferred from rocktype. The composite is a dual of averages for the high-\/k laminations and the w-\/k ones.

\doxylink{classcsmp_1_1_model}{Model} Concept


\begin{DoxyItemize}
\item compute the flow rate dependent saturations in the sublayers of the composite
\begin{DoxyItemize}
\item end-\/member cases\+:
\begin{DoxyItemize}
\item viscous limit (VL) where all saturations are the same, i.\+e. the saturation is uniform and equal to that of the cell
\item CL where pc(sw\+\_\+cell\+\_\+average) is the same everywhere, but the saturations in the layers reflect their pc curves these limiting cases are not directionaly dependent
\end{DoxyItemize}
\end{DoxyItemize}
\item compute the relperms, layer by layer
\item apply averaging to find the horizontal (weighted mean) and vertical (harmonic mean) relative permeability pairs
\item since this model does drainage only, relperm effects of spontaneous imbibition can be ignored
\end{DoxyItemize}

Implementation


\begin{DoxyItemize}
\item extended curve fitting and interpolation between the curves
\item there are only 2 flow directions\+: horizontal and vertical, switch occurs at 45o
\item the anisotropy of the absolute permeability, is treated by scaling the vertical relative permeabilities with Kv/\+Kh ratio
\item capillary pressure is also averaged, but for the vertical CL case a Brooks-\/\+Corey model is used, parameterised with the properties of the low permeability layer.
\item for primary drainage, the capillary entry pressure, pd of the lowest permeability layer is used
\end{DoxyItemize}

see Maple worksheet \textquotesingle{}BHP/\+Stanford-\/visit/\+IMPLEMENTATION/\+Heterogeneity\+Aware\+Saturation\+Functions\textquotesingle{}
