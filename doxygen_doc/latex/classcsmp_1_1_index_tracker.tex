\doxysubsection{Detailed Description}
Keeps track of all \doxylink{structcsmp_1_1_index}{Index} objects once they have been registered. 

Serves \doxylink{classcsmp_1_1_property_database}{Property\+Database} to keep all existing \doxylink{structcsmp_1_1_index}{Index} objects objects up to date, which is necessary when new variables are created at runtime.

\begin{DoxyNote}{Note}
index tracking is necessary because some classes have indices as members. These objects can get invalidated when new variables of the same kind and place. are created. If so, for instance, the 5th scalar on the node might become the 10th.
\end{DoxyNote}
By tracking all \doxylink{structcsmp_1_1_index}{Index} objects that exist in a model, these can be updated by the \doxylink{classcsmp_1_1_property_database}{Property\+Database} everytime a variable is created or deleted.

\begin{DoxyNote}{Note}
this implementation is based on the "{}\+Observer"{} design pattern.
\end{DoxyNote}
