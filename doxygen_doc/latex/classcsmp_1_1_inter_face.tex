\doxysubsection{Detailed Description}
\subsubsection*{template$<$uint32\+\_\+t dim$>$\newline
class csmp\+::\+Inter\+Face$<$ dim $>$}
Surface (3D) or line (2D) element connector for elements which share faces but not nodes. 

To connect disconnected patches of a mesh, facilitating the application of tractions, boundary fluxes etc. and for the representation of jump discontinuities of variables discretised on the nodes and interpolated with the element interpolation functions\hypertarget{classcsmp_1_1_split_boundary_conventions}{}\doxysubsection{\texorpdfstring{Conventions}{Conventions}}\label{classcsmp_1_1_split_boundary_conventions}
For compatibility (usage conformance) with the \doxylink{classcsmp_1_1_face}{Face} and the \doxylink{classcsmp_1_1_element}{Element}, a range of methods are retained which make sense only, however, if the side of the interface is specified. For this purpose,

current\+\_\+side\+\_\+

allows to set the state of the \doxylink{classcsmp_1_1_inter_face}{Inter\+Face} to INSIDE, OUTSIDE or MIDDLE; default is INSIDE.

If one wants to acces the nodes of an interface in the way one is used to from \doxylink{classcsmp_1_1_element}{Element} or \doxylink{classcsmp_1_1_face}{Face}, the method

Inter\+Face\+::\+N( n\+\_\+node, interface\+\_\+side ) has to be used.

The nodes are ordered sequentially, INSIDE nodes first, then outside nodes. The inside nodes follow the numbering of the nodes of the face of the higher-\/dimensional element on the inside. The outside nodes follow the face-\/node number of the OUTSIDE parent element. This means that they are stored in the opposite order as those on the inside.

Inside and outside nodes start out to be matched (by point location). Because of their different ordering (demanded to get the correct normals), the first inside node matches the last outside node. It follows that 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keyword}{auto}\ n\_nodes\ =\ \mbox{\hyperlink{classcsmp_1_1_finite_element_policy_aa15ab6c8637cfc881bba2a5068034fa1}{FE}}()-\/>Nodes()\ \textcolor{comment}{//\ of\ the\ finite\ element\ type\ of\ the\ interface.}}
\DoxyCodeLine{\textcolor{keywordflow}{for}\ (\ \textcolor{keyword}{auto}\ i\{0U\};\ i<n\_nodes;\ i++\ )}
\DoxyCodeLine{\ \ assert(\ \mbox{\hyperlink{classcsmp_1_1_inter_face_abc296812926dcaf14b4955e09c358962}{N}}(0,INSIDE)-\/>Coordinate()\ ==\ \mbox{\hyperlink{classcsmp_1_1_inter_face_abc296812926dcaf14b4955e09c358962}{N}}(n\_nodes-\/i-\/1U,OUTSIDE)-\/>Coordinate()\ );}

\end{DoxyCode}
 should not fail.

The normal to the interface points from the INSIDE to the OUTSIDE element of the \doxylink{classcsmp_1_1_inter_face}{Inter\+Face} and it is inherited from the lower dimensional element that the \doxylink{classcsmp_1_1_inter_face}{Inter\+Face} (or \doxylink{classcsmp_1_1_face}{Face}) was built from. The boolean variable collocated\+\_\+nodes, tells whether the nodes on opposite sides of the \doxylink{classcsmp_1_1_inter_face}{Inter\+Face} are collocated, meaning that they have the same location (collocated\+\_\+nodes=true) or whether they were separated over the course of a simulation (collocated\+\_\+nodes=false). Default is true.

If the nodes are not collocated, the \doxylink{classcsmp_1_1_inter_face_a5426cc263a39d5e18c78ac5449233c67}{Unit\+Normal()} method will return the normal to the mirror symmetry plane between the 2 sides of the \doxylink{classcsmp_1_1_inter_face}{Inter\+Face}.

Nodes in the middle can only be accessed if the MIDDLE element pointer has been assigned to a lower-\/dimensional intervening element inside of the \doxylink{classcsmp_1_1_inter_face}{Inter\+Face}. If this is indeed the case, then access it via Base\+Element(). The base (\doxylink{classcsmp_1_1_element}{csmp\+::\+Element}) of the \doxylink{classcsmp_1_1_inter_face}{Inter\+Face} is a nullptr by default, but it can be connected to an intervening lower-\/dimensional element mesh once the \doxylink{classcsmp_1_1_inter_face}{Inter\+Face} has been created.

\begin{DoxyNote}{Note}
Inter\+Faces are not listed as parents in their nodes.
