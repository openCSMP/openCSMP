void csmp\+::\+Interfaces\+\_\+\+Example\+::\+Run (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [virtual]}}

Builds CSMP native format models (binary files) using various interfaces, including ANSYS, SKUA, ECLIPSE, RHINO, TRIANGLE, etc. User can select which model to build or build all the models that shall be used in other examples. For this purpose, existing "{}default"{} files from the directory example\+\_\+inputs/ will be used.

\begin{DoxyAttention}{Attention}
To run the Open\+CSMP examples, please copy the \textquotesingle{}example\+\_\+inputs/\textquotesingle{} directory to a location outside of the open-\/csmp repository as you do not want the repository to track your experimentation with the examples.. Set this new directory as the working directory of your IDE (CLion, XCode, QT\+\_\+\+Creator, MS Vis Studio etc.). Look at the 3 sub directories of example\+\_\+inputs/ after running the example. They should contain\+:
\end{DoxyAttention}

\begin{DoxyItemize}
\item "{}input\+\_\+meshes/"{} contains mesh files that can be read by Open\+CSMP interfaces;
\item \textquotesingle{}csmp\+\_\+native\+\_\+format\+\_\+models/\textquotesingle{} that contains Open\+CSMP native format binary files (\texorpdfstring{$\ast$}{*}.vset and \texorpdfstring{$\ast$}{*}.dat files);
\item \textquotesingle{}variables\+\_\+and\+\_\+configuration\+\_\+files/\textquotesingle{} (\texorpdfstring{$\ast$}{*}.txt files) containing variable lists and model configuration files.
\end{DoxyItemize}

\textquotesingle{}bitmaps\+\_\+and\+\_\+other/\textquotesingle{} contains misc files that can serve the creation of CSMP native models

\begin{DoxyNote}{Note}
Typically the name of these files represents the name of the model with an argument like \textquotesingle{}-\/variables.\+txt\textquotesingle{} of \textquotesingle{}-\/configuration.\+txt\textquotesingle{} see CSMP users guide.
\end{DoxyNote}
Creating new subdirectories in your new working directory, this \doxylink{classcsmp_1_1_interfaces___example_a6f17ae8b9480fe22a44758504b948e95}{Run()} functions will\+:

1) create an example directory from its name (i.\+e., \textquotesingle{}example\+\_\+outputs/example\+\_\+name/\textquotesingle{});

2) recover default input files from the \textquotesingle{}example\+\_\+inputs/\textquotesingle{} directory, copy them into the example directory

3) produce all outputs in the created example directory (note\+: if an example directory already exists, it will be overwritten).

\begin{DoxyNote}{Note}
to use your own inputs, please copy the input files into corresponding sub directories of \textquotesingle{}example\+\_\+inputs/\textquotesingle{}
\end{DoxyNote}
\begin{DoxyAttention}{Attention}
Again\+: do not create your working directory anywhere inside the cloned open-\/csmp repository! 
\end{DoxyAttention}
