The global interpolation function derivative matrix is returned into the second method argument. The method also returns the determinant of the Jacobian matrix since it is often needed in integration procedures.

void Linear\+Line\+Element\+::\+N( const Element\& e, vector$<$double$>$\& FN, const vector$<$double$>$\& xy )

Description\+:

Computes the values of the interpolation functions at the global coordinate \textquotesingle{}xyz\textquotesingle{}. Since a Jacobian matrix can only be obtained for points which lie inside the local tetrahedron, such a transformation cannot be performed here. Because of this reason global area-\/coordinate functions are employed to obtain the interpolation function values at the global point.

Note, that the use of global interpolation functions implies that the method only gives highly accurate results if the element boundaries are not curved.\hypertarget{group___c_s_m_pglobal_functions_arguments}{}\doxysubsection{\texorpdfstring{Input Arguments}{Input Arguments}}\label{group___c_s_m_pglobal_functions_arguments}
The parent \doxylink{classcsmp_1_1_element}{Element}, the vector which will hold the interpolation function values, and the coordinate vector \textquotesingle{}xyz\textquotesingle{} in the global coordinate system. Note that if the global coordinates given by \textquotesingle{}xyz\textquotesingle{} do not lie within the global extent of the quadratic triangular element, the interpolation function values will no longer add to one and the interpolation will then be erroneous.

The second method argument, the vector FN, will be filled with the interpolation function values as computed at the point \textquotesingle{}xyz\textquotesingle{}.\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
The inverse of the Jacobian matrix is found for the global point \textquotesingle{}xyz\textquotesingle{}. Then \textquotesingle{}xyz\textquotesingle{} transposed is pre-\/multiplied with the Jacobian to find the local coordinate pair \textquotesingle{}rs\textquotesingle{} corresponding to \textquotesingle{}xyz\textquotesingle{}. Using these local coordinates the interpolation function values are found.\hypertarget{group___c_s_m_pglobal_enums_application}{}\doxysubsection{\texorpdfstring{Application Examples}{Application Examples}}\label{group___c_s_m_pglobal_enums_application}
To interpolate a property value withing the quadratic triangular element.
