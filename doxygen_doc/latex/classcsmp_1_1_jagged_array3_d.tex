class csmp\+::\+Jagged\+Array3\+D$<$ T $>$}
Three-\/dimensional jagged array (where the number of columns can vary), implemented via an unordered\+\_\+map plus hashing function \textquotesingle{}\doxylink{structcsmp_1_1_tuple_hash}{Tuple\+Hash}\textquotesingle{} Tested and compared in \textquotesingle{}\doxylink{classcsmp_1_1_jagged_array3_d___comparison___test}{Jagged\+Array3\+D\+\_\+\+Comparison\+\_\+\+Test}\textquotesingle{}. For dense regularly shaped matrix, \doxylink{classcsmp_1_1_jagged_array3_d}{Jagged\+Array3D} is slower than \doxylink{class_dynamic_array3_d}{Dynamic\+Array3D} and a vector of vecto of vectors. Good uses are for sparse 3D matrices the entries of which are in a flux (changing rapidly during a computation).
