\doxysubsection{Detailed Description}
Implementation of relative permeability model of Maartje Boon for layered rocktypes = composities. The values are supplied by parameter table that initialises model for rocktype. Documentation in Maple worksheet \textquotesingle{}Maartje\+\_\+relperms\textquotesingle{}.

Calculation procedure


\begin{DoxyEnumerate}
\item for given rocktype, table is initialised from file
\item Average saturation values, sw are calculated for each row for the given capillary number
\item The relative permeability is calculated by linear interpolation between the rocks of interest, for the wetting and the nonwetting phase
\end{DoxyEnumerate}

This model is meant to be extended to the case where horizontal relperms differ from vertical ones.

The input table is supposed to have the following format (\# comment lines to be ignored).
