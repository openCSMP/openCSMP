class csmp\+::\+Line\+Element\+Mesher$<$ dim $>$}
Line element mesher\+: collection of functions.

Creates polyline meshes that of an arbitrary dimension (like a spiral in 3D space). The meshes can contain duplicated nodes and INTERNAL boundaries.

\begin{DoxyAttention}{Attention}
Mesher does not assign \doxylink{group___c_s_m_pglobal_enums_ga8e4421c3cd02f67e535bceb2dc74bfb6}{BOX\+\_\+\+BOUNDARY} flags nor neighbor connectivity
\end{DoxyAttention}
