Computes the values of the interpolation functions at the global coordinate \textquotesingle{}xyz\textquotesingle{}. Since a Jacobian matrix can only be obtained for points which lie inside the local tetrahedron, such a transformation cannot be performed here. Because of this reason global area-\/coordinate functions are employed to obtain the interpolation function values at the global point.

Note, that the use of global interpolation functions implies that the method only gives highly accurate results if the element boundaries are not curved.\hypertarget{group___c_s_m_pglobal_functions_arguments}{}\doxysubsection{\texorpdfstring{Input Arguments}{Input Arguments}}\label{group___c_s_m_pglobal_functions_arguments}
The parent \doxylink{classcsmp_1_1_element}{Element}, the vector which will hold the interpolation function values, and the coordinate vector \textquotesingle{}xyz\textquotesingle{} in the global coordinate system. Note that if the global coordinates given by \textquotesingle{}xyz\textquotesingle{} do not lie within the global extent of the quadratic triangular element, the interpolation function values will no longer add to one and the interpolation will then be erroneous.
