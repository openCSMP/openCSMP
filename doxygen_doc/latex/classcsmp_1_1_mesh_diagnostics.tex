summary\+: diagnostics including checks/reports negative element orientations, flat elements, zero volumes etc. 

Method tries to test the current finite-\/element mesh for internal consistency. Thus it checks whether there are no gaps in the mesh object numbering (e.\+g., node numbers which are larger than the actual number of nodes etc.), no zero segment lengths of elements, no NAN coordinates etc. The method will not report duplicate \doxylink{classcsmp_1_1_node}{Node} or Integration\+Point coordinates.\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
Thus far, scrutinize\+Mesh() assumes a fixed maximum dimension of 40\textquotesingle{}000km.\hypertarget{group___c_s_m_pglobal_enums_application}{}\doxysubsection{\texorpdfstring{Application Examples}{Application Examples}}\label{group___c_s_m_pglobal_enums_application}
scrutinize\+Mesh() is recommended if meshes from external tools are used in CSMP computations. Its performance is fast, and while it does not guarantee for the detection of all possible errors many very obvious errors are reported.\hypertarget{group___c_s_m_pglobal_functions_messages}{}\doxysubsection{\texorpdfstring{Messages}{Messages}}\label{group___c_s_m_pglobal_functions_messages}
At the end of the test the method will write a few mesh diagnostics to stdout\+:

"{}horizontal min, max coordinate "{}vertical min, max coordinate "{}length of longest segment "{}length of shortest segment "{}maximum segment length ratio "{}minimum segment length ratio

SKM fix 18/10/2014\+: additions to catch exceptions associated with negative Jacobians.
