\doxysubsection{Detailed Description}
\doxylink{classcsmp_1_1_model}{Model} topology associates elements with regions and boundaries, recording their names, element types, and their dimensionality. This is important in model construction process. The \doxylink{classcsmp_1_1_model_topology}{Model\+Topology} thus stores this "{}topologic"{} information, which cannot be stored in the \doxylink{classcsmp_1_1_v_set}{VSet}.

In CSMP regions are model subdomains, just as boundaries and split boundaries. All of these can be stored in the \doxylink{classcsmp_1_1_model_topology}{Model\+Topology}. They are distinguished only by their names. Thus, a \doxylink{classcsmp_1_1_boundary}{Boundary} either contains the string BOUNDARY in its name or has one of the standard names for boundaries and or edges of box-\/shaped models (BOTTOM, TOP, LEFT, RIGHT, BACK, FRONT, IRREGULAR etc., EDGE1..EDGE12. Likewise, \doxylink{classcsmp_1_1_split_boundary}{Split\+Boundary} objects contain the string SPLITBOUNDARY in their name, typically separated by underscores from other more specific parts of the name.

\begin{DoxyAttention}{Attention}
It follows that the user has to assign appropriate names to the geometrical entities in their model that they want to become boundaries.
\end{DoxyAttention}
\doxylink{classcsmp_1_1_model}{Model} topology can also be used to perform a consistency check on the cells stored in the \doxylink{classcsmp_1_1_v_set}{VSet}. Thus, it can check the cell numbering and the neighbor connectivity. To some degree it can also fix such potential problems with the \doxylink{classcsmp_1_1_v_set}{VSet}.

When the model is supposed box-\/shaped, this is tested and potentially missing information is restored in collaboration with the \doxylink{classcsmp_1_1_v_set}{VSet} / \doxylink{classcsmp_1_1_v_data}{VData} and \doxylink{classcsmp_1_1_box}{Box}. In this case it can deduce the correct \doxylink{group___c_s_m_pglobal_enums_ga8e4421c3cd02f67e535bceb2dc74bfb6}{BOX\+\_\+\+BOUNDARY} flags and assign them to the nodes.

When a model is created by ANSYS and output using the CSMP interface of ANSYS the information needed to initialise the Model\+Toplogy class is contained in the \textquotesingle{}.asc\textquotesingle{} file.\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
\doxylink{classcsmp_1_1_model_topology}{Model\+Topology} was created to convey topological information from an ANSYS model to CSMP so that corresponding named groups of elements can be created and assigned specific material properties. ~\newline


For this purpose, \doxylink{classcsmp_1_1_model_topology}{Model\+Topology} stores named maps of the element IDs and types that make up specific model regions. By default, the element names are the ANSYS element names as captured inside the class \doxylink{classcsmp_1_1_a_n_s_y_s___element_specifications}{ANSYS\+\_\+\+Element\+Specifications}. Functionality is there in the public interface to convert these into CSMP names.

Since one does not always want to use all topological information and or finite elements in a simulation, \doxylink{classcsmp_1_1_model_topology}{Model\+Topology} allows the user to reduce the initial topology as, for instance, obtained from ANSYS\textquotesingle{}s meshing tools, to a few target regions -\/ or element types, such as only the volume elements. Several interfaces are provided for this purpose. ~\newline
\hypertarget{classcsmp_1_1_v_data_structure}{}\doxysubsection{\texorpdfstring{Structure}{Structure}}\label{classcsmp_1_1_v_data_structure}
\doxylink{classcsmp_1_1_model_topology}{Model\+Topology} assumes a complementary role to the \doxylink{classcsmp_1_1_v_set}{VSet} which stores the connectivity between elements and their nodes. Thus, there must always be a supporting \doxylink{classcsmp_1_1_v_set}{VSet} in order to build a \doxylink{classcsmp_1_1_model}{Model}. When the \doxylink{classcsmp_1_1_model_topology}{Model\+Topology} is reduced to a subset of the original model, corresponding operations must be performed on the \doxylink{classcsmp_1_1_v_set}{VSet}.
