\doxysubsection{Detailed Description}
\subsubsection*{template$<$uint32\+\_\+t dim$>$\newline
class csmp\+::\+Mohr\+Coulomb\+Failure$<$ dim $>$}
Using the current local stress state stored on the model in the variable "{}stress"{}, this \doxylink{classcsmp_1_1_interrelation}{Interrelation} subclass computes the failure criterion \textquotesingle{}failure\textquotesingle{} performing a Mohr Coulomb analysis, but without consideration of the fluid pressure.

To apply this interrelation the following discretised variables need to be defined\+:

"{}stress"{}, "{}mean stress"{}, "{}cohesion"{}, "{}failure"{}.
