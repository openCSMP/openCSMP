\doxysubsection{Detailed Description}
Allows redirection of the output streams cout and cerr from the screen to null (output goes nowhere) and file (ascii file) 

Class is used to suppress output on systems where the user has no access to the console and/or where sceen output would dramatically slow the computations.

Only a single stream can be handled by an instance, so return values will reflect that.

Application example\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{Mute\ mute;}
\DoxyCodeLine{cout\ <<\ \textcolor{stringliteral}{"{}\(\backslash\)nMute\ mode...\(\backslash\)n"{}};}
\DoxyCodeLine{mute.Null(cout);\ \textcolor{comment}{//\ or\ i.e.\ mute.File(\ cout,\ "{}Output.txt"{});}}
\DoxyCodeLine{}
\DoxyCodeLine{\textcolor{comment}{//\ ...\ here\ goes\ the\ main\ code\ with\ supressed\ output}}
\DoxyCodeLine{}
\DoxyCodeLine{mute.Reinstate(cout);}

\end{DoxyCode}
