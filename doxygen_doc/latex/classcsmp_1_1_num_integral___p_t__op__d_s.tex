Calculates the surface integral over the boundary face of the element and assigns this contribution in a weighted fashion to the boundary nodes in the righthand vector. Since we checked for NEUMANN in Get\+Operand() we don\textquotesingle{}t need to do it here. Vector components are set to zero otherwise.
