\subsubsection*{template$<$uint32\+\_\+t dim$>$\newline
class csmp\+::\+Overburden\+Pressure\+Visitor$<$ dim $>$}
For a given Sv (overburden stress at the model top), this visitor computes\+:


\begin{DoxyItemize}
\item the (hydraulic) \textquotesingle{}conductivity\textquotesingle{} from the element \textquotesingle{}permeability\textquotesingle{} and (nodal) \textquotesingle{}fluid viscosity\textquotesingle{}
\item (nodal) \textquotesingle{}gravity force\textquotesingle{} scalar variable as the product of g (specified by user) and the \textquotesingle{}dry rock density\textquotesingle{} specified as element property.
\item the (element) \textquotesingle{}gravity term\textquotesingle{} vector variable used in for the integration of the fluid density via the corresponding PDE operator.
