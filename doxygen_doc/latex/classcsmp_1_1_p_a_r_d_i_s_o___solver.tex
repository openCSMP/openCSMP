\doxysubsection{Detailed Description}
Interface to the direct PARDISO solver from the MKL library. Derived from \doxylink{classcsmp_1_1_solver}{Solver} class, following CSMP\textquotesingle{}s strategy design pattern for the solution of linear algebraic systems of equations.

\begin{DoxyNote}{Note}
works only if there is access to the MKL library.
\end{DoxyNote}
