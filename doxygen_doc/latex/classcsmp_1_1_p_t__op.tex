class csmp\+::\+PT\+\_\+op$<$ dim, CELL $>$}
\doxylink{classcsmp_1_1_point}{Point} sources, loads etc. for vector solution variable. In mechanics, this operator is known as nodal force vector. 

\begin{DoxyAuthor}{Author}
S.\+K. Matthai 

S. Roberts 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2000
\end{DoxyDate}
Use this operand to accumulate nodal vector-\/type properties flagged Dirichlet into the righthand side of the global matrix equation.

The forces are distributed onto the Dirichlet nodes such that nodes which are shared by two elements are accumulated correctly\+:

F(midpoint node) = (F / boundary-\/nodes) F(corner node) = (F / boundary-\/nodes) / 2
