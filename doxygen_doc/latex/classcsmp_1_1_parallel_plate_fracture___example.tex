2D steady-\/state calculation of parallel-\/plate permeability in a fracture set that is represented by a surface mesh. Subsequently, fluid pressure distribution is computed using a quadratic finite-\/element approximation. Dirichlet essential conditions are applied at left and right boundaries.

Later, the model is saved to a binary file and a new model is built from the vset file. The Dirichlet pressure boundary conditions are changed, the pressure is recomputed and the results are written to file

Use input mesh file set\+: veins\+\_\+20k.\+1 as generated by program Triangle.

You can use either Paraview of the TCL/\+TK viewer \textquotesingle{}example\+\_\+viewer.\+tcl\textquotesingle{} to visualize output.
