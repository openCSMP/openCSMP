\doxysubsection{Detailed Description}
Using the point data in the supplied spreadsheet, \doxylink{classcsmp_1_1_point_property_to_cell_mapper2_d}{Point\+Property\+To\+Cell\+Mapper2D} creates a vector of cell pointers that are non-\/null if they contain points are are part of the target region. This set is then used for the mapping of values to the mesh or back to the point set.
