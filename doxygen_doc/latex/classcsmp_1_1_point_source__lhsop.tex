\doxysubsection{Detailed Description}
\subsubsection*{template$<$uint32\+\_\+t dim, template$<$ uint32\+\_\+t $>$ class CELL = Element$>$\newline
class csmp\+::\+Point\+Source\+\_\+lhsop$<$ dim, CELL $>$}
Assignment of scalar nodal (Neumann) source or sink terms. 

This operator applies (absolute) nodal source terms to the LHS matrix diagonal as they are. The nodal values must be precomputed elsewhere.

\begin{DoxyAttention}{Attention}
the nodal term gets applied as many times as the node is a member of an element, i.\+e. n.\+Parents() times. Therefore the value should be divided by the number of parent elements of the node. This is already accounted for by the method \doxylink{classcsmp_1_1_point_source__lhsop_a534375a81c3de1cd82a56eb402eb8bb9}{Get\+Operands()}.
\end{DoxyAttention}
