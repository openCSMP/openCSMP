\subsubsection*{template$<$uint32\+\_\+t dim$>$\newline
class csmp\+::\+Pore\+Volume\+Visitor$<$ dim $>$}
Calculating the volume and pore volume of a node-\/centered control volume.

\begin{DoxyAuthor}{Author}
Philipp Weis, ETH Zuerich 
\end{DoxyAuthor}

@changes changes Latest Changes\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
Intitially designed to avoid the usage of the Finite\+Volume\+Manager in csp5. Output as nodal field variables allows to use them for post-\/processing (e.\+g. with Para\+View or Mat\+Lab).\hypertarget{classcsmp_1_1_upwind_control_visitor_usage}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{classcsmp_1_1_upwind_control_visitor_usage}
Used within the CVFEM scheme (Weis et al., Geofluids, 2014).


\begin{DoxyCode}{0}
\DoxyCodeLine{The\ visitor\ reads\ in\ a\ nodal\ variable\ \textcolor{keywordflow}{for}\ porosity,\ which\ has\ to\ be\ initialised\ before\ visitation}
\DoxyCodeLine{It\ further\ \textcolor{keyword}{requires}\ existing\ nodal\ variables\ \textcolor{keywordflow}{for}\ volume\ and\ pore\ volume.}
\DoxyCodeLine{The\ three\ variable\ names\ are\ provided\ as\ constructor\ arguments.}
\DoxyCodeLine{}
\DoxyCodeLine{\ \ The\ visitor\ calculates\ the\ node-\/centered\ volume\ and\ pore\ volume,\ assuming\ that\ all\ elements\ contribute\ equally\ to\ the\ control\ volumes\ of\ their\ respecetive\ nodes.}
\DoxyCodeLine{}
\DoxyCodeLine{The\ values\ \textcolor{keywordflow}{for}\ volume\ and\ pore\ volume\ are\ stored\ as\ nodal\ variables.}

\end{DoxyCode}
