void csmp\+::\+Pressure\+Diffusion\+\_\+\+Example\+::\+Run (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [virtual]}}

2D transient calculation of fluid pressure distribution using a triangular element mesh generated by the program Triangle (file set\+: frac30.\+1). Quadratic finite element interpolation is used and Dirichlet essential conditions are applied. After computing an initial left-\/right fluid pressure gradient, the pressure on the left is dropped to a low value and the response of the model is computed in a time stepping loop.

Use VTK example\+\_\+viewer.\+tcl or Paraview to visualize vtk output.
