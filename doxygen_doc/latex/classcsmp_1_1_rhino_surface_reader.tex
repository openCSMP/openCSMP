\doxysubsection{Detailed Description}
Reads triangulated render meshes of surfaces output from Rhinoceros (Mc\+Neel\&Associates) and converts them into a 3D \doxylink{classcsmp_1_1_v_set}{VSet} that can be read by CSMP.

Multiple surfaces are distinguished using the object names from Rhino.

Go\+CAD output\+: TSurf format\+: surfaces selected by the user through stdin. 

Writes a series of files which contain one surface each corresponding to the selected surfaces from the Rhino \textquotesingle{}.raw\textquotesingle{} dataset. The names of the objects are appended to the output file names which start with the supplied file name. A hyphen is put between the filename and the object name.
