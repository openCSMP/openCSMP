Factoring out SAMG tuning parameter in a separate class so that they can be changed indepently of the solver object.\hypertarget{classcsmp_1_1_two_phase_implicit_node_centered_f_v_transport_design}{}\doxysubsection{\texorpdfstring{Design Intent}{Design Intent}}\label{classcsmp_1_1_two_phase_implicit_node_centered_f_v_transport_design}
\doxylink{classcsmp_1_1_s_a_m_g___settings}{SAMG\+\_\+\+Settings} objects store SAMG tuning parameter. These tuning parameter are divided into switches and their subswitches.

Each switch can be accessed by its respective Get-\/method and its subswitches can be set using the respective Set-\/methods.

Every Set-\/method checks if the input data conforms to the restrictions imposed by the SAMG solver. If the input value is invald, a domain\+\_\+error exception is thrown.

\begin{DoxyWarning}{Warning}
Only the rules for the subswitch itself are checked! Interdependencies between subswitches are NOT checked! The user is responsible to guarantee that all subswitches together form a meaniful parametrization for the SAMG solver. 
\end{DoxyWarning}
