\doxysubsection{Detailed Description}
Subclass of \doxylink{classcsmp_1_1_solver}{Solver} for linear algebra computations conducted with SAMG, the algebraic multigrid solver for systems of equation from SCAPOS, Fraunhofer, Germany. 

Solves the linear algebraic system A x = b using the algebraic multigrid solver DLL from SCAI, Fraunhofer Gesellschaft (St. Augustin, Bonn), which can be obtained from SCAPOS.

Up to 2 istances of the DLL can be communicated with. SAMG iteration cycles benchmark criterion. 

\hypertarget{group___c_s_m_pglobal_functions_arguments}{}\doxysubsection{\texorpdfstring{Input Arguments}{Input Arguments}}\label{group___c_s_m_pglobal_functions_arguments}
Below functions are called only if NO\+\_\+\+PRIMARY\+\_\+\+SOLVER\+\_\+\+CONTROL is defined by the user.

When SAMG solver settings allow reuse of coarsening setups for subsequent time steps it must be ensured that it is still applicable to the problem. The below function has access to the SAMG output parameter ncyc\+\_\+done\+\_\+ and stores the lowest number of performed iteration cycles required to reach convergence (ncyc\+\_\+best\+\_\+). If the criterion can not be fulfilled a new SAMG solver setting is enforce by adjusting the SAMG paramters iswtch before it is passed on to the solver call. Subsequent solver calls will query the unaffected iswit setting of the \doxylink{classcsmp_1_1_s_a_m_g___settings}{SAMG\+\_\+\+Settings} instance and hence resume reusing the new solver setup.
