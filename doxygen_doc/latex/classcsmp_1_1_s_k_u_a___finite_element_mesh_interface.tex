\doxysubsection{Detailed Description}
File based interface between SKUA and CSMP. 

To provide a direct file-\/based interface between the SKUA\textquotesingle{}s Finite\+Element\+Mesher and CSMP, allowing to read parts of the input mesh selectively, assign material properties, boundary conditions and to rigorously test the incorporated mesh for its compliance with CSMP requirements.

Part of the file format of this interface is modelled on the SKUA interface using the classes \doxylink{classcsmp_1_1_v_set}{VSet}, FEM\+\_\+\+Primitive and \doxylink{classcsmp_1_1_model_topology}{Model\+Topology} to store the information retrieved from file.\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
Two files\+: one human readable text (.asc = ASCII) file and a binary (.dat) file that can be transferred across platforms (Windows OSX, linux etc/). Both files have the same name (model name) and are distinguished only by their extension.

\item Comment line (header)\+: 1. filename, 2. date of generaton
\item Number of labelled objects
\item Table with objects, element types, material ID values (rock types), number of elements (cells)
\end{DoxyItemize}

\begin{DoxyEnumerate}
\item ELEMENT AND NODE PROPERTIES
\end{DoxyEnumerate}

Following the material ID record of integers, the property data block starts. Since the properties have different placements (element, node etc.) and types (scalar, vector, tensor, array, flagged-\/array), this information must be specified alongside with the property name. Furthermore, by contrast with \doxylink{classcsmp_1_1_vector_variable}{Vector\+Variable} (dim) and \doxylink{classcsmp_1_1_tensor_variable}{Tensor\+Variable} (dim x dim), the size of which is defined by the model dimension, dim, \doxylink{classcsmp_1_1_array_variable}{Array\+Variable} and \doxylink{classcsmp_1_1_flagged_array_variable}{Flagged\+Array\+Variable} have a length (number of entries) that is defined at runtime and therefore has to be specified. While each \doxylink{classcsmp_1_1_array_variable}{Array\+Variable} has only one flag, each \doxylink{classcsmp_1_1_flagged_array_variable}{Flagged\+Array\+Variable} has one flag per value. For this reason, flag strides and data strides are provided for all variables.

In summary, a complete record for a CSMP variable consists of\+:

name(string) placement(enum PLACEMENT) type (\doxylink{group___c_s_m_p__global__enumerations_gacbf62c758c46dc45b3f024638bb89274}{VARIABLE\+\_\+\+TYPE}) (array length (int32)) number of data entries (int32) flag values (int32) property values (double)
