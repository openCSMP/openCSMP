\doxysubsection{Detailed Description}
Class is used to initialise uniform properties of lower-\/dimensional sandbodies so that an application of the Brooks-\/\+Corey model will yied the correct input parameters for an element with a certain dip etc.

While the model needs \textquotesingle{}total velocity\textquotesingle{} as an input, all other properties are calculated locally.
