\doxysubsection{Detailed Description}
\doxylink{classcsmp_1_1_scalar_variable}{Scalar\+Variable} combines a floating point value with a flag that specifies its use during computations. 

\begin{DoxyAuthor}{Author}
S.\+K. Matthai 

Stephen G. Roberts 

S. Geiger 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2001
\end{DoxyDate}
Associates a floating point variable with a flag for the purpose of special treatment in finite-\/element computations. Operators are defined so that \doxylink{classcsmp_1_1_scalar_variable}{Scalar\+Variable} behaves essentially like a double, but flags can be set, their values compared and the variable can be used together with \doxylink{classcsmp_1_1_vector_variable}{Vector\+Variable} and \doxylink{classcsmp_1_1_tensor_variable}{Tensor\+Variable} for the representation of physical variables in CSMP computations. The \doxylink{classcsmp_1_1_scalar_variable}{Scalar\+Variable} type is templatized to allow its use with variables of different precision. The default use is with \textquotesingle{}double\textquotesingle{} variables defined as 8-\/byte doubles.\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
For the purpose of multiphysics computations, variable flags must be combined with variable values and not with nodes, faces, or elements, because several variables may be specified in such locations and their flags may differ. Also range checking against the property database needs to be possible for physical variables.\hypertarget{classcsmp_1_1_visitor_applicability}{}\doxysubsection{\texorpdfstring{Applicability}{Applicability}}\label{classcsmp_1_1_visitor_applicability}
Scalar-\/ are used together with Vector-\/ and Tensor\+Variables to implement CSP property computations.\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
The types of Scalar-\/ are used together with Vector-\/ and Tensor\+Variables are linked with the enum \doxylink{group___c_s_m_p__global__enumerations_gacbf62c758c46dc45b3f024638bb89274}{VARIABLE\+\_\+\+TYPE} (SCALAR,VECTOR,TENSOR) for efficient discrimination (not depending on RTTI). They are stored in the Memory\+Manager object for each \doxylink{classcsmp_1_1_model}{Model}. The storage requirement for the flag is 1-\/byte. Thus, the total storage required for a double scalar is 9 bytes (8 for the floating-\/point value and 1 for the flag).\hypertarget{classcsmp_1_1_visitor_examples}{}\doxysubsection{\texorpdfstring{Application Examples}{Application Examples}}\label{classcsmp_1_1_visitor_examples}
