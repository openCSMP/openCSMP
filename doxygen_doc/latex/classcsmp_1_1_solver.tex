\doxysubsection{Detailed Description}
Inverts global solution matrices matrices of the finite-\/element computations using a variety of solution procedures sparse matrices (class \doxylink{classcsmp_1_1_sparse_matrix}{Sparse\+Matrix}). \doxylink{classcsmp_1_1_solver}{Solver} base class in strategy pattern.

\hypertarget{classcsmp_1_1_two_phase_implicit_node_centered_f_v_transport_design}{}\doxysubsection{\texorpdfstring{Design Intent}{Design Intent}}\label{classcsmp_1_1_two_phase_implicit_node_centered_f_v_transport_design}
To encapsulate numerical algebraic methods in an object which services the \doxylink{classcsmp_1_1_p_d_e___integrator}{PDE\+\_\+\+Integrator} and other class objects.\hypertarget{classcsmp_1_1_visitor_applicability}{}\doxysubsection{\texorpdfstring{Applicability}{Applicability}}\label{classcsmp_1_1_visitor_applicability}
Currently the solver offers an algebraic multigrid method (AMG), a conjugate gradient method (CG), and a Gaussian elimination method (GE) as solution schemes. Gaussian elimination can be applied to non-\/symmetric matrices as they arise if advection-\/dispersion matrices are accumulated into the global solution matrix. The algebraic multigrid and conjugate gradient methods require symmetric positive-\/definite (no negative elements in the diagonal) solution matrices in order to be applicable.

Dependent on the size of the computation different solution methods are appropriate\+: If you have a very small test problem, like a 30 x 30 matrix, CG ist as fast or faster than AMG and it will require less storage. Above a size of 50 x 50, AMG becomes much faster than the other methods.\hypertarget{classcsmp_1_1_solver_participants}{}\doxysubsection{\texorpdfstring{Participants}{Participants}}\label{classcsmp_1_1_solver_participants}
Each inversion involves a sparse global solution matrix of type Sp\+Mat, a righthand, and a solution vector of type \doxylink{classvector}{vector$<$double$>$}.\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
The \doxylink{classcsmp_1_1_solver}{Solver} uses the Meschach++ and the AMG libraries to carry out the matrix operations. The user sets the private variable solution method, whose default is algebraic multigrid.\hypertarget{classcsmp_1_1_visitor_examples}{}\doxysubsection{\texorpdfstring{Application Examples}{Application Examples}}\label{classcsmp_1_1_visitor_examples}
The \doxylink{classcsmp_1_1_solver}{Solver} is called by the Algorithm and Algorithm objects, when they are submitted to the \doxylink{classcsmp_1_1_model}{Model} through its Apply() interfaces. In this process the Algorithm hands the solver the global solution matrix \textquotesingle{}G\textquotesingle{}, the solution vector \textquotesingle{}x\textquotesingle{} and the righthand vector \textquotesingle{}rh\textquotesingle{}.\+:

Calls solution methods from the Meschach++ and algebraic multigrid libraries to invert the global solution matrix. If the solution process fails, the solution matrix and the righthand vector are output to textfiles whose name contains the runtime in seconds and which have the extension \textquotesingle{}.text\textquotesingle{}.

After successful matrix inversion, the solution vector is returned into \textquotesingle{}x\textquotesingle{}.\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
Solve\+Matrix\+Equation() first tries to calculate a "{}typical"{} size of the residual (the difference between the exact and the numerical solution). Secondly, based on this residual it sets the \textquotesingle{}tolerance\textquotesingle{} for the matrix inversion. This involves an initial guess with correct boundary conditions and assumes that the righthand vector b has been setup with Dirichlet boundary conditions and the solution matrix with corresponding 1\textquotesingle{}s on its diagonal.

If the matrix inversion fails, Solve\+Matrix\+Equation() calls the method \doxylink{classcsmp_1_1_solver_afb9380e536b4d7080c89cf143421c6f2}{Out()} on the solution matrix and the righthand vector.\hypertarget{group___c_s_m_pglobal_enums_application}{}\doxysubsection{\texorpdfstring{Application Examples}{Application Examples}}\label{group___c_s_m_pglobal_enums_application}
Everytime an Algorithm is passed to the \doxylink{classcsmp_1_1_model}{Model}, its computation involves the solution of a matrix equation.\hypertarget{group___c_s_m_pglobal_functions_messages}{}\doxysubsection{\texorpdfstring{Messages}{Messages}}\label{group___c_s_m_pglobal_functions_messages}
If verbose is enabled the method will print out the solution matrix, the solution vector, and the righthand vector. Also it will report a gues of the initial residual and the actual residual of the obtained solution\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{Typical\ initial\ Residue\ \ \ =\ 5.21798}
\DoxyCodeLine{Residual\ after\ solution\ \ \ =\ 3.58661e-\/16}

\end{DoxyCode}


Important is that this output gives the ratio between the typical initial residue and the residual after the solution (here 1.\+0e+16). This ratio is essentially the signal-\/to-\/noise ratio and must (as a minimum for the solution to be meaningful), be greater than the ratio between the largest and the smallest dependent-\/variable value which was specified as initial or as boundary condition. ~\newline
