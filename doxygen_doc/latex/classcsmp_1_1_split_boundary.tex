\doxysubsection{Detailed Description}
\subsubsection*{template$<$uint32\+\_\+t dim$>$\newline
class csmp\+::\+Split\+Boundary$<$ dim $>$}
Representation of a model boundary across which the elements are node-\/matching, but have unique nodes on either side; as many nodes as come together. 

\begin{DoxyAuthor}{Author}
P. Lang 

S.\+K. Matthai 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2011
\end{DoxyDate}
Split\+Boundaries are collections of Inter\+Faces (interior material boundaries) singled out for specific computations.\hypertarget{classcsmp_1_1_split_boundary_conventions}{}\doxysubsection{\texorpdfstring{Conventions}{Conventions}}\label{classcsmp_1_1_split_boundary_conventions}
The base class node pointer vector contains nodes of the inner side of the split boundary. If one wants to access neighboring nodes, this would be done via looping over the boundaries interfaces and use Inter\+Face\+::\+N(i,j).\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
Split boundaries split the nodes of the provided \doxylink{classcsmp_1_1_boundary}{Boundary} plus those that belong to another \doxylink{classcsmp_1_1_boundary}{Boundary} as well. Hence, use of Boundaries is required where all external and internal boundaries of the domain are represented as such (exist as a \doxylink{classcsmp_1_1_boundary}{csmp\+::\+Boundary}).

Opposing parent elements on either side of the \doxylink{classcsmp_1_1_boundary}{csmp\+::\+Boundary} are removed from each others neighbor list, so they are from the now duplicated nodes parent list on the opposing side.

\begin{DoxyAttention}{Attention}
Before andy Split\+Boundaries may be built all Boundaries have to be set up. 

2D models in 3D space will not allow for proper split boundary creation (unit normal of line element issue)
\end{DoxyAttention}
\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
To address and carry out computations at material interfaces or model boundaries.

To avoid conditional processing (if at boundary statements etc.) for all elements of a model, by treating boundary specific calculations separately.\hypertarget{classcsmp_1_1_two_phase_implicit_node_centered_f_v_transport_consequences}{}\doxysubsection{\texorpdfstring{Consequences}{Consequences}}\label{classcsmp_1_1_two_phase_implicit_node_centered_f_v_transport_consequences}
\doxylink{classcsmp_1_1_split_boundary}{Split\+Boundary} objects permit the implementation of jump discontinuities in continuum models, see Tran et al. (2020, AWR)

\begin{DoxyNote}{Note}
\doxylink{classcsmp_1_1_split_boundary}{Split\+Boundary} has no \doxylink{group___c_s_m_pglobal_enums_ga8e4421c3cd02f67e535bceb2dc74bfb6}{BOX\+\_\+\+BOUNDARY} flag because it can only have the value INTERNAL anyway. 
\end{DoxyNote}
