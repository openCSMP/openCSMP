Analysis of steady-\/state fluid pressure and velocity distributions in fractured medium using quadratic FEM.

Post-\/processing of the streamfunction that can be contoured to get streamlines.

\doxylink{classcsmp_1_1_example}{Example} also allows to vary the permeability of model subregions (addressed by their name) and calculates its effective permeability.

Try \textquotesingle{}example21.\+1\textquotesingle{} input file set.
