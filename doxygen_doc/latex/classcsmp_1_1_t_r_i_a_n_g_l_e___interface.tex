Reads the series of mesh output files from Setchuk\textquotesingle{}s triangle mesher. The data from the text files are used to build a \doxylink{classcsmp_1_1_v_set}{VSet} which holds all the necessary information to initialize a CSMP mesh, including property data and boundary flags.

However, Setchuk\textquotesingle{}s mesher numbers nodes and elements from 1..n and CSMP wants them numbered 0..n-\/1. Therefore a conversion is performed to adjust this numbering before the \doxylink{classcsmp_1_1_v_set}{VSet} is returned.

The methods expects x files with the extensions \textquotesingle{}.edge\textquotesingle{}, \textquotesingle{}ele\textquotesingle{}, \textquotesingle{}.neigh\textquotesingle{}, \textquotesingle{}.node\textquotesingle{} and \textquotesingle{}.poly\textquotesingle{}. The neighbor element file (\textquotesingle{}.neigh\textquotesingle{}) is not generated automatically by triangle, but must be prompted for by using the \textquotesingle{}-\/n\textquotesingle{} command line option. It contains a list of neighboring elements for each triangle.\hypertarget{group___c_s_m_pglobal_functions_arguments}{}\doxysubsection{\texorpdfstring{Input Arguments}{Input Arguments}}\label{group___c_s_m_pglobal_functions_arguments}

If a 2D triangular finite element has two of its sides on the boundary of the model, this poses problems when boundary conditions are assigned because one always first has to identify the correct model side and secondly because elements rarely are compliant enough to satisfactorily handle the different conditions. ~\newline


The remedy used here, is to find the elements element neighbor and to create a segment from the corner node and the node diametrically opposite. This segment then separates two new elements which are created by flipping the two adjacent elements, example lower left corner\+: ~\newline

\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}

\begin{DoxyEnumerate}
\item In the pfverts array those elements are singled out which have only one neighbor. These elements must lie at the mesh corners.
\item If such an element is found, its neighbor is found as well in the plist. The element ID\textquotesingle{}s are remembered.
\item A segment (MJL\+\_\+\+Edge) is constructed from the corner node to the node diametrically opposite in the triangle.
\item Depending which mesh corner we are in, the two remaining nodes left and right of the new segment form corner nodes of the new triangles (MJL\+\_\+\+Triangle).
\item The new triangles are reassigned to the plist and the properties, if present are averaged and mapped back onto the elements. If both property values were the same, nothing is done.
\item The elements pfverts are re-\/assigned according to the new connectivity.
\item The elements adjacent to the flipped elements must be updated with regard to their neighbor lists.
