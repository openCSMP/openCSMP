Computation of a hydrostatic (pore) pressure profile in a sedimentary basin.

Illustration of how to use CSMP for one-\/dimensional models. Illustration of how to use the fluid equation of state (EOS) module.

Steps\+:


\begin{DoxyEnumerate}
\item First a vertical (1D) temperature profile is computed. This can be done in a single step because it is essentially independent on fluid density.
\item Using an initial guess of the water density of 1000 kg/m3 an iterative process is started where rho(p,\+T) is adjusted incrementally using the new pressure estimates. If no further change occurs (within a given tolerance), the (Picard) iteration is stopped.
\end{DoxyEnumerate}
