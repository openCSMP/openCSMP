\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
Template specialization implementing optimized tensors in CSP. Depending on the spatial dimension of the model, tensor variables are either 2 x 2 or 3 x 3 matrices. Each value is associated with a flag which can be set to indicate to finite-\/element computations that the corresponding degree of freedom is enabled or restricted.\hypertarget{classcsmp_1_1_tensor_variable_3_013_u_01_4_functionality}{}\doxysubsection{\texorpdfstring{Functionality}{Functionality}}\label{classcsmp_1_1_tensor_variable_3_013_u_01_4_functionality}
Apart from the standard constructors with a default where all elements are initialized to NaN (not-\/a-\/number) and the flags are set to plain, assignment is defined to allow the storage of tensors in STL containers. Ordering using STL\textquotesingle{}s less() is facilitated through an \doxylink{classcsmp_1_1_tensor_variable_3_013_u_01_4_a29a34396b9fbdfe553ea9f4e0567651e}{operator$<$()} that compares the determinants of matrices. All costly operations like this are unrolled.

\doxylink{classcsmp_1_1_tensor_variable}{Tensor\+Variable} implements typical accessors, mutators for tensor elements and operations on entire tensors. To get at element 1,2 of 3D tensor, ts, use ts(1,2), for instance.

Value-\/by-\/value operations such as matrix addition, subtraction, division are implemented by the operators +, -\/, /. operator\texorpdfstring{$\ast$}{*}() assumes different meanings dependent on the type of its arguments. Thus, tensors can be multiplied with scalars, vectors, and tensors to produce the standard results expected for matrix algebra. Other matrix algebraic operations include finding the \doxylink{classcsmp_1_1_tensor_variable_3_013_u_01_4_a1d41ea6ae2ab266732e0f39c8b2388b8}{Transposed()}, \doxylink{classcsmp_1_1_tensor_variable_3_013_u_01_4_a57738ffeca103afced2713d69b0ea43b}{Determinant()}, \doxylink{classcsmp_1_1_tensor_variable_3_013_u_01_4_ae2dbed54f20a5f66071af484bfe37e03}{Inverse()}, \doxylink{classcsmp_1_1_tensor_variable_3_013_u_01_4_aa5d0acb3049f7099a61713cdcb63bb6c}{Identity()}, and \doxylink{classcsmp_1_1_tensor_variable_3_013_u_01_4_a873b1d04b9158e96af55e29a349c8589}{Adjoint()} matrices.

The \texorpdfstring{$\ast$}{*}= operator will always produce a temporary matrix. Therefore, should be preferred if the result is to be assigned to a new variable.

Assignent of a vector to a tensor is done by placing the vector in the tensors diagonal and zeroing its off-\/diagonal elements.

Matrices can be input and output via the console, using the \doxylink{classcsmp_1_1_tensor_variable_3_013_u_01_4_a109d47446100a873a2116cd9617616a0}{In()} and \doxylink{classcsmp_1_1_tensor_variable_3_013_u_01_4_a6477d07d42ad2ad7e223cc554a0119a3}{Out()} member functions.\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
Part of a consistent framework for physical variables for which there exist overloaded operators so that vector-\/matrix multiplications and other operations can be written in a straight forward way.\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
Using the template specialization mechanism of C++. Specializations exist only for the 2 and 3D cases. These are declared in this (3D) and the header file \textquotesingle{}\doxylink{_tensor_variable2_8h_source}{Tensor\+Variable2.\+h}\textquotesingle{} (2D), respectively.\hypertarget{classcsmp_1_1_visitor_examples}{}\doxysubsection{\texorpdfstring{Application Examples}{Application Examples}}\label{classcsmp_1_1_visitor_examples}
