\doxysubsection{Detailed Description}
\doxylink{classcsmp_1_1_test}{Test} base class for unit testing.

Usage example\+:
\begin{DoxyEnumerate}
\item define default constructor and run() function
\item in run() function, use the macros provided to test whether desired conditions apply or not.
\end{DoxyEnumerate}

Examples\+:
\begin{DoxyItemize}
\item check whether the floating point value, a, is equal to b within given tolerance, tol\+:

\+\_\+equal(a,b,tol);
\item check whether a boolean conditions applies\+:

\+\_\+test(isoparametric==false);
\item add a message to a failure report\+:

\+\_\+fail("{}for this input this did not work"{});
\item report that a test passed\+: if (...) \+\_\+succeed();
\end{DoxyItemize}

Obtain a fail/succeed report after running the test.

test.\+report();
