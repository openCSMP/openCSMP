2D steady-\/state calculation of fluid pressure distribution using structured triangular element meshes generated by CSMP\textquotesingle{}s \doxylink{classcsmp_1_1_triangulator}{Triangulator} from color-\/coded bitmaps. Linear finite element interpolation is used and Dirichlet essential conditions are applied.

To learn how to create text matrices from the 256-\/color coded images, read User Guide, Chapter 6 (input and output from CSMP).

\begin{DoxyNote}{Note}
Build your own model or use \textquotesingle{}granite\+\_\+model1\textquotesingle{} as input geometry (needs fast solver)
\end{DoxyNote}
