\doxylink{classcsmp_1_1_example}{Example} program that uses a mesh created with ANSYS-\/\+ICEM FE to build the \doxylink{classcsmp_1_1_model}{Model} and simulate incompressible two-\/phase flow using an IMPES (Implicit Pressure Explicit Saturation) or IMPIS (Implicit Pressure Implicit Saturation) approach based on the FE-\/\+FV scheme of CSMP. Output is written to Matlab files and individual groups are monitored

Tasks and exercises\+:


\begin{DoxyEnumerate}
\item Generate a 2D ANSYS mesh with a new geometry, check comphg.\+wikidot.\+com for a small how-\/to
\item Compare results for implicit and explicit FV schemes and different timestepping.
\item Compare results for homogeneous porous media to the analytical solution for the Buckley-\/\+Leverett problem
\item Allow the user to define, at runtime (!), to choose between a different relperm models available in the two\+\_\+phase directory
\item Design and program a \doxylink{classcsmp_1_1_visitor}{Visitor} that computes the total mobility and phase mobilities using the kr-\/model that the user defines. Get together as a team to compare your visitors and generate a final version for the SVN (NB\+: The visitor should check that the results are within range and give error statements if the wrong variable placements are used or variables are not defined)
\item Program a function that computes the capillary pressure at the element center as well as the derivative dpc/dS
\item Program a diffusion algorithm, using the FE method, to solve the non-\/linear diffusion equation for the capillary pressure, i.\+e. phi d\+S/dt = div \texorpdfstring{$\ast$}{*} ( lambda\+\_\+star dpc/dS grad S )
\item Compare simulations with and without capillary effects for explicit/implicit FV schemes and different time-\/steps. Analyse how the FV simulation of capillary spreading compares to your FE algorithm 
\end{DoxyEnumerate}
