3D full specialization of vector-\/type variable template (2D vectors are in files \#1, \#2).

Implements basic vector variable type that consists of dim=spatial dimensions entries (options are 2 x 1 and 3 x 1 for 2D and 3D models, respectively) plus as many variable flags as vector elements. The flags are of type enum \doxylink{group___c_s_m_p__global__enumerations_ga98d2031b830da37499a1b512d9dca4b9}{VARIABLE\+\_\+\+FLAG}. ~\newline
 \doxylink{classcsmp_1_1_vector_variable}{Vector\+Variable} is defined as a C++ template for the 2D and 3D cases (In 1D you should use \doxylink{classcsmp_1_1_scalar_variable}{Scalar\+Variable} to represent vector type properties). ~\newline


NOTE\+: The definitions of the 2D constructors are in the file \doxylink{_vector_variable2_8h_source}{Vector\+Variable2.\+h}. ~\newline
\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
A plain STL vector cannot be used to implement this datatype since there is a need to flag each vector entry so that it can receive a special treatment in a finite element computation, i.\+e. as a fixed (Dirichlet) boundary value or the like. Also there is a need to make vector operations as efficient as possible. This has been done by unrolling all loops.\hypertarget{classcsmp_1_1_visitor_applicability}{}\doxysubsection{\texorpdfstring{Applicability}{Applicability}}\label{classcsmp_1_1_visitor_applicability}
Any kind of computations that involve Scalar-\/, Vector-\/, or \doxylink{classcsmp_1_1_tensor_variable}{Tensor\+Variable} objects in CSMP. For standard element-\/by-\/element calculations, operators are provided. This includes special operators like \textquotesingle{}\texorpdfstring{$^\wedge$}{\string^}\textquotesingle{} which will calculate the power of each vector element for the user-\/specified value. Slightly odd is the use of the operators \& and \% for the scalar and the cross products of vectors, respectively (there are no better options, try maybe templatized enums, suggestions are welcome).

All vector operations are already unrolled to give best performance. Temporaries are eliminated as far as is possible and all \texorpdfstring{$\ast$}{*}=, /=, +=, -\/=, dot and cross product, and \doxylink{classcsmp_1_1_vector_variable_3_013_u_01_4_a7dfae6eb1c258c64840396955b018fe5}{Length()} operators / member functions have no overhead due to assigments of flags. Hence there is nothing to be gained from additional handcoding of such operations.\hypertarget{classcsmp_1_1_visitor_examples}{}\doxysubsection{\texorpdfstring{Application Examples}{Application Examples}}\label{classcsmp_1_1_visitor_examples}
