\doxysubsection{Detailed Description}
Accessor for discretized physical variables. 

Link between \doxylink{classcsmp_1_1_property_database}{Property\+Database} and \doxylink{classcsmp_1_1_local_variable_storage}{Local\+Variable\+Storage}.

P. Lang 

S. Geiger 

Stephen G. Roberts
\end{DoxyAuthor}
\hypertarget{compare_floats_8h_motivation}{}\doxysubsection{\texorpdfstring{Motivation}{Motivation}}\label{compare_floats_8h_motivation}
Class encapsulates the three values that are required to retrieve a CSP variable from a model based on an unstructured mesh\+: The Type() distinguishes scalars, vectors and tensors from one-\/another since these have different storage requirements.

The Place() specifies whether a variable is discretized on the nodes, elements, faces or on constraint points. This has implications as to how the variable is interpolated over the model domain.

The \doxylink{structcsmp_1_1_index_a4a84f8220a8133265973a50d2062ff33}{Index()} is used internally by CSMP for housekeeping. It corresponds to the number that the variable has in an alphabetically ordered map of variables of the same type and placement, in the same model.\hypertarget{classcsmp_1_1_two_phase_implicit_node_centered_f_v_transport_design}{}\doxysubsection{\texorpdfstring{Design Intent}{Design Intent}}\label{classcsmp_1_1_two_phase_implicit_node_centered_f_v_transport_design}
Create a universal accessor for discretized physical variables in a model.\hypertarget{classcsmp_1_1_visitor_applicability}{}\doxysubsection{\texorpdfstring{Applicability}{Applicability}}\label{classcsmp_1_1_visitor_applicability}
Typically, a \doxylink{structcsmp_1_1_index}{csmp\+::\+Index} or \doxylink{structcsmp_1_1_index}{Index} object is initialized only once before it is used as an accessor to variables in a model. The initialization is done by the \doxylink{classcsmp_1_1_property_database}{Property\+Database} if so requested.

\doxylink{structcsmp_1_1_index}{Index} is applicable whereever the parallel structure \doxylink{structcsmp_1_1_index}{csmp\+::\+Index} is applicable. The reason, why a class is present in addition to the structure is that this allows to assign default values when indices are constructed.\hypertarget{classcsmp_1_1_time_step_evaluator_collaborations}{}\doxysubsection{\texorpdfstring{Collaborations}{Collaborations}}\label{classcsmp_1_1_time_step_evaluator_collaborations}
\doxylink{structcsmp_1_1_index}{Index} is known to the \doxylink{classcsmp_1_1_property_database}{Property\+Database} and all variable accessor and mutator functions. It is used by \doxylink{classcsmp_1_1_property_handle}{Property\+Handle} and \doxylink{classcsmp_1_1_operand}{Operand} objects, as well as Interrelations, Visitors and Algorithms to housekeep currently used variables.\hypertarget{namespacecsmp_implementation}{}\doxysubsection{\texorpdfstring{Implementation}{Implementation}}\label{namespacecsmp_implementation}
Both as struct \doxylink{structcsmp_1_1_index}{csmp\+::\+Index} and this class.\hypertarget{classcsmp_1_1_visitor_examples}{}\doxysubsection{\texorpdfstring{Application Examples}{Application Examples}}\label{classcsmp_1_1_visitor_examples}
