This directory contains a (hopefully growing) list of CSMP tutorials, which show how to model some basic physical problems
with CSMP++. Each directory contains its own *.pro file, which allows the user/developer to build a stand-alone executable
for the given tutorial. Input files as well as some Matlab scripts for visualisation are provided as well.

The complexity of the tutorials increases with increasing tutorial number.

Tutorial 1
==========

Pressure diffusion using triangular analytical FEs and a 2D mesh that was generated by the Triangulator. 

Appears to work ok with CSMP++ (SG, 15-09-2011)

Tutorial 2
==========

Single-phase solute transport problem on regular FE mesh (quadrilaterals) with isoparametric elements.

The following issues occured when porting from CSP to CSMP++ (as of 15-09-2011)

* Explicit transport 1st and 2nd order yield identical results, the 2nd order method appears not to work although
  all 2nd order FV functions in ExplicitFiniteVolumeTransport and ExplicitStencilProcessor are called. The 1st and
  2nd order results of CSMP++ are identical to the 1st order results of CSP.

* The implicit transport does not work: When the SAMG solver is called for the 2nd time during the implicit transport step,
  CSMP++ crashes without an error message immediately before the SAMG solver is executed in SolveMatrixEquation() in
  NodeCenteredFiniteVolumeTransport

* It should be confirmed if the CFL criterion in the function AnisotropicCourantIncrement should be multiplied with porosity,
  which was not the case in CSP where transport worked fine. This leads to critically small time-steps in explicit schemes with
  lower-dimensional fractures where the porosity is multiplied by fracture aperture.

* The function CFL_Multiplier() in NodeCenteredFiniteVolumeTransport() appears to set the variable cfl_multiplier_ which is
  never used in the code as the CFL multiplier is now set in AdvectVariable(). This may lead to confusion if CFL_Multiplier() is
  used but the actual CFL number is never changed.
  
  Tutorial 3
============

Two-phase incompressible transport with explicity and semi-implicit time-stepping. 

Interestingly, SAMG does not stop in implicit calculation and results are identical with old CSP. 1st and 2nd order explicit 
schemes have non-physical inflow from the now-flow boundaries. 

NB: This is a relatively homogeneous model. If large time-steps are chosen in the implicit method (which is actually semi-
implicit as df/ds is evaluated at t, not t+Dt) the front lags behind the true solution and results from the explicit transport.
Christine is fixing this through a fully implicit approach with Newtwon iteration.

  Tutorial 4
============

Solving Stokes flow for 2D pore geometries using the finite element method. A coupled FE algorithm is setup that solves for velocity
and pressure simultaneously, using an FE stabilisation parameter which allows us to use the same FE basis functions for pressure
and velocity instead of quadratic basis functions for velocity and linear for pressure. This tutorial uses a crude hack to assign
a flux boundary condition, which should be replaced once the PDE_Integrator can be used to integrate fluxes over (model) boundaries.
Pore geomery is from a grain stone thin section. Model is rescaled to approximate the dimension of the original thin section.

For details on the numerical scheme see Zaretskiy, Geiger, Sorbie and Foerster Advanced in Water Resources (2010), doi:10.1016/j.advwatres.2010.08.008
