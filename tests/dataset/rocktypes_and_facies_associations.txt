# =======================================================================================
# Explanations
# ------------
# - The description of each rocktype starts with its name, integer code,
#   and basic (multiphase) flow properties.
# - The Leverett-J-function J(sw) may follow. If so, it is specified as follows:
#     - number of value pairs specifying the tabulated J function
#     - derivate1 and derivative_n at the function origin and endpoints, respectively.
#     - sw-J(sw) value pairs (one per line) 1..n   
# - This datablock is followed by tabulated curves for krw, krn, pc(sw),
#   including their derivatives at the saturation endpoints.
#   Note that saturation endpoints of these curves must match those given
#   in the data block above, i.e. must be the beginning and end points.
#
# - The multiphase flow properties can be followed by 4 groups of 
#   additional rocktype attributes = keywords:
#   1. 'geologic characteristics'
#   2. 'mineralogy'
#   3. 'mechanical properties'
#   4. 'thermal properties'
#   these have the following subcategories:
#   1. geologic:
#      EOD, facies, bedform, sorting, grainsize distribution, 
#      finest-fraction, roundness, sphericity, poreshape, tortuosity
#   2. mineralogic (volume fractions of the minerals):
#      quartz, feldspar, calcite, illite, kaolinite, smectite, oxides, sulfides,
#      and lithics
#   3. mechanical:
#      Young's modulus, Poisson's ratio, compressibility, friction coefficient, 
#      Biot coefficient, unconfined compressive strength (UCS), tensile strength
#   4. thermal:
#      thermal conductivity,	heat capacity, radiogenic heat production
#
# - Rocktype descriptions are separated by blank lines
#     
# - Any rocktype can be an association of multiple types = 'facies association' 
#   = 'composite'. The number in the line after the type identifier indicates
#   how many lithologies make up the rocktype, and these are listed in an order of 
#   descending permeability.
# - In such a composite, the different datablocks are repeated.
#
# - If experimentally determined saturation functions are available for a rocktype,
#   there is a statement, 'tabulated saturation functions', and
#  'drainage' and 'imbibition' keywords indicate which curves are recorded.
# - only primary curves are recorded.
# - there is only a single set of experimentally determined curves for each rocktype
#   irrespective of whether it is a composite or not 
#
# - Tokens (variable values etc.) are delimited by tabs since variable names contain whitespace.
# - Comments can be inserted anywhere in this file, starting with the pound (#) sign
#   any text behind the pound sign is ignored
# - all values are to be given in SI units using scientific notation
# - NO_DATA values are marked by NO_DATA, no_data, or no-data
#
# - When this file is read, property values are range-checked against the values in
#   the "-variables.txt" file.
# - This interface builds on the text-file reading functions in csmp::TextFileIO.h
# =======================================================================================
